Featured
RISING FILL + KEY TURN

The vault fills, then locks

It fills top-to-bottom in passes, each a step darker — warm grey marching to solid black. At black the keyhole turns, as if a key clicked it locked, then eases back to light and climbs again. JS-driven; the richest treatment, best for a full-page / first load.

Other options · CSS only

01 · Rising fill. Vault fills bottom-to-top — reads as progress. The pick for a primary inline loader.

02 · Shimmer. A light passes over the solid lock. Subtle, premium, never distracting.

03 · Breathe. Scale + opacity pulse. Simplest; holds up at the smallest sizes.

04 · Trace. Outline draws itself, then erases. Crafty, signature feel.

05 · Orbit. Spinner ring around a static lock. Instantly reads as “loading.”
