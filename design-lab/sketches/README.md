# StudyVault background sketches

Drop the hand-drawn sketch assets here (PNG with transparent background, or SVG).
Suggested: post-it notes, pencils/pens, paperclips, stars, checklists, arrows,
highlighter marks, coffee rings, "exam!" notes, etc.

They get positioned across the long scrollable background layer in
`design-lab/bg-layer.html` (currently using stand-in SVG doodles).

Naming: anything is fine — e.g. `postit-revise.png`, `pencil.png`, `paperclip.svg`.
Once they're here, I'll swap them in for the placeholders and we position together
(drag mode + "Copy positions" in the dev bar).
