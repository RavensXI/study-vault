StudyVault — wordmark & brand mark

The canonical lockup: “Study” in medium, “Vault” in heavy, closed by the padlock as the full stop. Everything below is live — the CSS and markup under “Build it” are the single source to reuse on other pages and promotional material.

The mark alone

Use the mark on its own for the favicon, app icon, social avatar and watermarks. Standalone vector: assets/studyvault-lock.svg (transparent keyhole, recolour via fill).

Build it

CSS

.sv-wordmark{display:inline-flex;align-items:baseline;line-height:1;
  font-family:'Schibsted Grotesk',system-ui,sans-serif;
  font-weight:500;letter-spacing:-.012em;color:currentColor}
.sv-wordmark b{font-weight:800}                /* "Vault" carries the weight */
.sv-lock{height:.28em;width:.225em;margin-left:.04em;
  align-self:baseline;fill:currentColor;flex:none}   /* seats as the full stop */

HTML

<span class="sv-wordmark">Study<b>Vault</b><svg class="sv-lock"
     viewBox="512 384 1023 1280" aria-hidden="true">
  <mask id="kh">
    <rect x="512" y="384" width="1023" height="1280" fill="#fff"/>
    <path fill="#000" d="…keyhole path…"/>
  </mask>
  <path fill="currentColor" mask="url(#kh)" d="…body path…"/>
</svg></span>

The two d path values live in assets/studyvault-lock.svg — copy them straight in. Colour comes from currentColor, so the lockup inherits whatever text colour you set on it. If you place more than one lockup on a page, give each mask a unique id.
