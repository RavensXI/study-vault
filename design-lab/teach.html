How this is calculated. Every number on this page is aggregated from retrieval-practice evidence students already generate while revising — warm-up answers, lesson quiz scores, shorts recall checks — each one tied to a lesson and unit. Recall accuracy is a retention signal, not an ability judgement: low numbers mean "this hasn't stuck yet", and clusters across the class are reteach signals. The only AI on the page is the weekly brief (one small-model call per class per week, ≈1p) and the stored practice-marking feedback, which was already generated when each student pressed "mark" — nothing reasons per student per page-view.
