<h2 data-narration-id="n1">Properties of Digital Image Files</h2>
<p data-narration-id="n2">Every digital image is made up of tiny coloured squares called <dfn class="term" data-def="The smallest individual unit of a digital image, displayed as a tiny coloured square on screen.">pixels</dfn>. The more pixels an image contains, the more detail it can show. Understanding the properties of image files — resolution, pixel dimensions, and colour depth — is essential for choosing the right format and quality settings for different uses.</p>
<h2 data-narration-id="n3">Resolution: DPI and PPI</h2>
<p data-narration-id="n4">Resolution describes how much detail an image contains. It is measured in two ways depending on whether the image is displayed on screen or printed on paper.</p>
<p data-narration-id="n5"><strong><dfn class="term" data-def="Pixels Per Inch — the number of pixels contained within one inch of an image displayed on a screen.">PPI</dfn></strong> (Pixels Per Inch) refers to the number of pixels contained within one inch of an image displayed on a computer monitor or screen. A higher PPI means more pixels are packed into each inch, producing a sharper, more detailed image on screen.</p>
<p data-narration-id="n6"><strong><dfn class="term" data-def="Dots Per Inch — the number of printed dots contained within one inch of an image produced by a printer.">DPI</dfn></strong> (Dots Per Inch) refers to the number of printed dots contained within one inch of an image printed by a printer. A higher DPI produces a clearer printed image with smoother gradients and finer detail.</p>
<div class="key-fact" data-narration-id="n7" data-revision-tip="Cover this box. Recall the resolution or dimension specifications here.">
<div class="key-fact-label">Key Fact</div>
<p><strong>PPI</strong> is for screens, <strong>DPI</strong> is for printing. Web images typically use 72 PPI. Print images need at least 300 DPI for sharp, professional-quality output.</p>
</div>
<p data-narration-id="n8"><strong>Pixel dimensions</strong> describe the width and height of an image in pixels (e.g. 1920 × 1080). Larger pixel dimensions mean more detail, but also a larger file size. An image with dimensions of 3000 × 2000 pixels contains 6 million pixels (6 megapixels). If you enlarge a bitmap image beyond its original pixel dimensions, it becomes blurry or “pixelated” because the existing pixels are stretched to fill a larger area.</p>
<h2 data-narration-id="n9">Bitmap (Raster) vs Vector Images</h2>
<p data-narration-id="n10">Digital images fall into two fundamental categories: <strong>bitmap</strong> (also called raster) and <strong>vector</strong>. Understanding the difference is critical for choosing the right format.</p>
<p data-narration-id="n11">A <dfn class="term" data-def="A digital image composed of a grid of pixels, where each pixel stores colour information. Also called a raster image.">bitmap</dfn> (or raster) image is made up of a grid of pixels. Each pixel stores colour information. Photographs are always bitmap images. File sizes tend to be larger because every pixel must be stored. If a bitmap image is enlarged, it becomes blurry and pixelated because the pixels are stretched. Common bitmap formats include JPEG, PNG, GIF, TIFF, and BMP.</p>
<figure class="diagram"><img src="https://pub-aeb94e100e5a48f4a133be5bf206aecb.r2.dev/creative-imedia/distribution-and-media/diagram_generated_3ba1abc1.jpg" alt="Generated diagram for Image File Properties and Compression"><figcaption>Generated diagram for Image File Properties and Compression</figcaption></figure>
<p data-narration-id="n12">A <dfn class="term" data-def="A digital image made up of mathematical shapes such as lines, curves, and fills, which can be scaled to any size without losing quality.">vector</dfn> image is made up of mathematical shapes — lines, curves, and fills defined by coordinates and equations. Vector images can be scaled to any size without losing quality, because the shapes are recalculated at each new size rather than stretched. File sizes are generally smaller than bitmaps. Vector images are ideal for logos, icons, diagrams, and illustrations. Common vector formats include SVG and PDF.</p>

<p data-narration-id="n13"><strong>Bitmap:</strong> Made of pixels. Best for photographs. Large file sizes. Loses quality when enlarged. Formats: JPEG, PNG, GIF, TIFF, BMP.</p>
<p data-narration-id="n14"><strong>Vector:</strong> Made of mathematical shapes. Best for logos, icons, illustrations. Small file sizes. Scales without quality loss. Formats: SVG, PDF, EPS.</p>

<h2 data-narration-id="n15">Image File Formats</h2>
<p data-narration-id="n16">Different image file formats have different properties that make them suitable for specific uses. The exam requires you to know the properties and limitations of each format and when to use them.</p>
<div class="collapsible">
<button class="collapsible-toggle" aria-expanded="false">
<span>Standard Image File Formats</span>
<svg class="collapsible-icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><polyline points="6 9 12 15 18 9"/></svg>
</button>
<div class="collapsible-content"><div class="collapsible-inner">
<p data-narration-id="n17"><strong>JPEG (.jpg)</strong> — Bitmap format using <strong>lossy compression</strong>. Reduces file size by permanently removing some image data. Best for photographs and web images where small file size matters. Standard web resolution is 72 PPI. Does not support transparency. Every time a JPEG is edited and re-saved, quality decreases slightly.</p>
<p data-narration-id="n18"><strong>PNG (.png)</strong> — Bitmap format using <strong>lossless compression</strong>. Preserves all image data while reducing file size. Supports transparency (alpha channel), making it ideal for logos and web graphics that need to appear on different backgrounds. File sizes are slightly larger than JPEG. Standard web resolution is 96 PPI.</p>
<p data-narration-id="n19"><strong>GIF (.gif)</strong> — Bitmap format using <strong>lossless compression</strong>. Limited to 256 colours, making it unsuitable for photographs but useful for simple graphics and short animations. Supports transparency and frame-based animation. Very small file sizes.</p>
<p data-narration-id="n20"><strong>TIFF (.tiff)</strong> — Bitmap format that is typically <strong>uncompressed</strong> (though it can use lossless compression). Produces very high-quality images at 300 DPI, making it the standard format for professional printing. File sizes are very large. Not suitable for web use.</p>
<p data-narration-id="n21"><strong>BMP (.bmp)</strong> — The standard <strong>uncompressed</strong> bitmap format. Very high quality but produces extremely large file sizes. Rarely used for distribution; mainly used in image editing software.</p>
<p data-narration-id="n22"><strong>SVG (.svg)</strong> — A <strong>vector</strong> format that uses mathematical definitions rather than pixels. Scalable to any size without quality loss. Ideal for logos, icons, web illustrations, and diagrams. Small file sizes. Supported by all modern web browsers.</p>
<p data-narration-id="n23"><strong>RAW</strong> — An unprocessed image file captured directly from a digital camera sensor. Contains maximum image data for editing flexibility. Very large file sizes. Must be processed and exported to another format (JPEG, TIFF) before distribution. RAW is a native format — different cameras use different RAW formats (e.g. .dng, .nef, .cr2).</p>
</div></div>
</div>
<h2 data-narration-id="n24">File Compression for Images</h2>
<p data-narration-id="n25"><dfn class="term" data-def="The process of reducing a file's size for easier storage and transfer.">File compression</dfn> reduces the size of image files so they can be stored and transferred more efficiently. There are two types of compression:</p>
<p data-narration-id="n26"><strong>Lossy compression</strong> permanently removes some data to reduce file size. The removed data cannot be recovered. Each time the file is edited and re-saved, more data is lost and quality decreases further. JPEG is the most common lossy format. Lossy compression is best when small file sizes matter more than perfect quality (e.g. web images, social media posts).</p>
<p data-narration-id="n27"><strong>Lossless compression</strong> reduces file size without permanently removing any data. The original image can be perfectly reconstructed from the compressed file. PNG, GIF, and TIFF (when compressed) all use lossless compression. Lossless compression produces larger files than lossy but maintains full image quality.</p>
<div class="key-fact" data-narration-id="n28" data-revision-tip="Cover this box. List the file formats and their properties from memory.">
<div class="key-fact-label">Key Fact</div>
<p><strong>Lossy</strong> = smaller file, some quality lost permanently (JPEG). <strong>Lossless</strong> = larger file, no quality lost (PNG, GIF). The choice depends on whether file size or image quality is the priority.</p>
</div>
<div class="collapsible">
<button class="collapsible-toggle" aria-expanded="false">
<span>Native vs Standard File Formats</span>
<svg class="collapsible-icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><polyline points="6 9 12 15 18 9"/></svg>
</button>
<div class="collapsible-content"><div class="collapsible-inner">
<p data-narration-id="n29"><strong>Native file formats</strong> can only be opened by specific software. Examples: Adobe Photoshop (.psd), Adobe Illustrator (.ai), Affinity Designer (.afdesign), GIMP (.xcf), RAW camera files. These are used during editing and must be exported to a standard format for distribution.</p>
<p data-narration-id="n30"><strong>Standard file formats</strong> can be opened without specialist software and are used for final products. Examples: JPEG, PNG, GIF, TIFF, SVG, PDF, BMP.</p>

--- CONCLUSION_HTML ---
<h3 data-narration-id="n32">Key Takeaways</h3>
<ul><li data-narration-id="n33">PPI measures screen resolution (72 PPI for web), DPI measures print resolution (300 DPI for quality printing) — higher values mean more detail and larger file sizes.</li>
<li data-narration-id="n34">Bitmap images are made of pixels (best for photos, pixelate when enlarged); vector images use mathematical shapes (best for logos, scale without quality loss).</li>
<li data-narration-id="n35">Lossy compression (JPEG) reduces file size by permanently removing data; lossless compression (PNG, GIF) preserves all data but produces larger files. Format choice depends on the intended use.</li></ul>

--- EXAM_TIP_HTML ---
<p data-narration-id="n31">A common exam question asks: “What type of images maintain exactly the same quality regardless of how much the image size is increased?” The answer is <strong>vector images</strong> (not bitmap/raster). Remember: bitmaps pixelate when enlarged, vectors scale perfectly. For questions about choosing file formats, always link your answer to the <strong>use and context</strong> — state the format, explain why it suits the purpose (e.g. “JPEG for a website because its lossy compression keeps the file size small for fast loading”).</p>
