--- DESCRIPTION ---
Routers, switches, hubs, bridges, WAPs and NICs — what each does and why standards matter.

--- CONTENT_HTML ---
<h2 data-narration-id="n1">Why Network Hardware Matters</h2>
<p data-narration-id="n2">Every network is built from physical components that move data between devices. Understanding what each piece of hardware does &mdash; and why it differs from the others &mdash; is essential for your exam. You need to know six devices: <strong>router</strong>, <strong>hub</strong>, <strong>switch</strong>, <strong>bridge</strong>, <strong>wireless access point (WAP)</strong> and <strong>network interface card (NIC)</strong>.</p>

<h2 data-narration-id="n3">Routers</h2>
<p data-narration-id="n4">A <dfn class="term" data-def="A networking device that connects different networks together and directs data packets between them using IP addresses.">router</dfn> connects different networks together and directs data packets between them. When you type a web address at home, your router decides the best path for your request to take across the internet. Routers operate at the Network layer of the OSI model, reading <strong>IP addresses</strong> to make forwarding decisions.</p>
<p data-narration-id="n5">Most home routers also include a switch, a wireless access point and a modem all in one device, but in larger business networks these functions are handled by separate pieces of hardware.</p>

<h2 data-narration-id="n6">Switches</h2>
<p data-narration-id="n7">A <dfn class="term" data-def="A networking device that connects devices within a single network and forwards data only to the specific device it is addressed to, using MAC addresses.">switch</dfn> connects multiple devices within a single network &mdash; for example, all the computers in one classroom. Unlike a hub, a switch is intelligent: it maintains a table of <strong>MAC addresses</strong> so it can send data directly to the correct device rather than broadcasting it to everyone. This makes switches far more efficient than hubs and is why they are standard in modern networks.</p>

<h2 data-narration-id="n8">Hubs</h2>
<p data-narration-id="n9">A <dfn class="term" data-def="A basic networking device that connects multiple devices but broadcasts all incoming data to every connected device, regardless of the intended recipient.">hub</dfn> also connects multiple devices, but it has no intelligence. When a device sends data to the hub, the hub broadcasts it to every other connected device. The intended recipient reads it; all other devices discard it. This wastes bandwidth and creates security risks because any device can &ldquo;hear&rdquo; all traffic. Hubs have been almost entirely replaced by switches in real networks.</p>

<div class="key-fact" data-narration-id="n10" data-revision-tip="Cover this and explain in one sentence how a switch differs from a hub — focus on how each handles an incoming data frame.">
  <div class="key-fact-label">Key Fact</div>
  <p>A switch uses a MAC address table to deliver data only to the correct destination device. A hub broadcasts data to every connected device. This is why switches are more efficient and more secure than hubs.</p>
</div>

<h2 data-narration-id="n11">Bridges</h2>
<p data-narration-id="n12">A <dfn class="term" data-def="A networking device that joins two separate network segments and filters traffic between them using MAC addresses.">bridge</dfn> connects two separate network segments and decides whether to forward or block data based on MAC addresses. If a frame is destined for a device on the same segment it came from, the bridge drops it; if it is destined for the other segment, the bridge forwards it. Bridges reduce unnecessary traffic crossing between segments and can connect different media types (for example, copper and fibre).</p>
<p data-narration-id="n13">Bridges are similar to switches but operate between two segments rather than many ports. In modern networks, switches have largely replaced standalone bridges.</p>

<h2 data-narration-id="n14">Wireless Access Points (WAPs)</h2>
<p data-narration-id="n15">A <dfn class="term" data-def="A device that allows wireless devices to connect to a wired network using Wi-Fi (IEEE 802.11).">wireless access point (WAP)</dfn> allows devices such as laptops, smartphones and tablets to join a wired network without a physical cable. The WAP translates between the wireless (Wi-Fi) and wired (Ethernet) protocols. In a large building such as a school, multiple WAPs are placed throughout to give full coverage, all connected back to the same wired network infrastructure.</p>

<h2 data-narration-id="n16">Network Interface Cards (NICs)</h2>
<p data-narration-id="n17">A <dfn class="term" data-def="A hardware component inside a device that provides the physical interface for connecting to a network, assigned a unique MAC address at manufacture.">network interface card (NIC)</dfn> is the hardware component inside every networked device &mdash; computer, printer, smart TV &mdash; that handles the connection to the network. Each NIC is assigned a globally unique <strong>MAC address</strong> at manufacture. This 48-bit address is used by switches and bridges to identify devices. Modern devices have both a wired NIC (Ethernet port) and a wireless NIC (Wi-Fi) built in.</p>

<div class="key-fact" data-narration-id="n18" data-revision-tip="Without looking, name all six network hardware devices and write one key fact about each — what it does or how it differs from a similar device.">
  <div class="key-fact-label">Key Fact</div>
  <p>The six network hardware components you must know are: router (connects networks, uses IP addresses), switch (connects devices in a network, uses MAC addresses), hub (broadcasts to all devices), bridge (joins two segments, filters by MAC), WAP (wireless to wired connection) and NIC (the hardware interface inside every device, with a unique MAC address).</p>
</div>

<div class="collapsible">
  <button class="collapsible-toggle" aria-expanded="false">
    <span>Wired vs Wireless Connectivity</span>
    <svg class="collapsible-icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><polyline points="6 9 12 15 18 9"/></svg>
  </button>
  <div class="collapsible-content"><div class="collapsible-inner">
    <p data-narration-id="n19">Networks carry data over physical media (wired) or radio waves (wireless). Both have trade-offs that you may be asked to compare.</p>
    <p data-narration-id="n20"><strong>Wired (Ethernet)</strong> uses copper or fibre-optic cables to transmit data. Copper is cheaper but limited in speed and distance; fibre-optic uses pulses of light and offers much higher bandwidth over longer distances but is more expensive to install. Wired connections are more secure (a physical cable cannot easily be intercepted) and more reliable (no interference from walls or other devices).</p>
    <p data-narration-id="n21"><strong>Wireless (Wi-Fi)</strong> uses radio waves, allowing devices to connect without cables. This gives flexibility &mdash; users can move around while staying connected. However, wireless signals can be blocked by walls, interfered with by other devices using the same frequency, and intercepted more easily than a wired connection, creating security risks. Speed and range decrease with distance from the WAP.</p>
  </div></div>
</div>

<div class="collapsible">
  <button class="collapsible-toggle" aria-expanded="false">
    <span>Why Networking Standards Exist</span>
    <svg class="collapsible-icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><polyline points="6 9 12 15 18 9"/></svg>
  </button>
  <div class="collapsible-content"><div class="collapsible-inner">
    <p data-narration-id="n22">A <dfn class="term" data-def="An agreed set of rules that defines how hardware or software should behave to ensure devices from different manufacturers can work together.">networking standard</dfn> is an agreed set of rules that ensures devices from different manufacturers can communicate reliably. Without standards, a router from one company might not be able to talk to a switch from another.</p>
    <p data-narration-id="n23">The most important networking standards you need to know are:</p>
    <ul>
      <li data-narration-id="n24"><strong>IEEE 802.3 (Ethernet)</strong> &mdash; defines how devices connect over wired cables and how they take turns to transmit data.</li>
      <li data-narration-id="n25"><strong>IEEE 802.11 (Wi-Fi)</strong> &mdash; defines how wireless devices communicate using radio frequencies. The 802.11 family includes amendments for different speeds and frequencies (for example, 802.11ac operates on 5 GHz and supports speeds above 1 Gbps).</li>
    </ul>
    <p data-narration-id="n26">Standards are developed by international bodies such as the IEEE (Institute of Electrical and Electronics Engineers) so that manufacturers worldwide follow the same rules. This means you can buy any Wi-Fi router and connect any Wi-Fi-certified device to it, regardless of manufacturer.</p>
  </div></div>
</div>

--- CONCLUSION_HTML ---
<h3 data-narration-id="n28">Key Takeaways</h3>
<ul>
  <li data-narration-id="n29">Routers connect different networks and route packets using IP addresses; switches connect devices within one network and forward frames using MAC addresses; hubs broadcast to all devices and have been replaced by switches in modern networks.</li>
  <li data-narration-id="n30">Bridges join two network segments and filter traffic by MAC address; WAPs give wireless devices access to a wired network; NICs are the hardware interface inside every device, identified by a unique MAC address.</li>
  <li data-narration-id="n31">Networking standards (IEEE 802.3 for Ethernet, IEEE 802.11 for Wi-Fi) ensure that hardware from different manufacturers can communicate, making interoperability possible across the global internet.</li>
</ul>

--- EXAM_TIP_HTML ---
<p data-narration-id="n27">A very common exam error is confusing a switch with a hub. Remember: a hub broadcasts data to every device; a switch uses MAC addresses to send data only to the intended device. If a question asks you to &ldquo;compare a switch and a hub&rdquo;, you must include an explicit contrast using the words &ldquo;unlike&rdquo; or &ldquo;whereas&rdquo;. For questions on wired vs wireless, always mention both a technical difference (e.g. speed or interference) and a security difference &mdash; examiners reward multi-dimensional comparisons.</p>
