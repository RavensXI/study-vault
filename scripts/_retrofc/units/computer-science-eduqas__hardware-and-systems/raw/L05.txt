<h2 data-narration-id="n1">What Is an Embedded System?</h2>
<p data-narration-id="n2">When most people think of a computer, they picture a laptop or a desktop machine with a keyboard, screen and operating system. But the vast majority of computers in the world are not general-purpose machines &mdash; they are <dfn class="term" data-def="A computer system built into a larger device to perform a specific, dedicated function, usually in real time.">embedded systems</dfn>: computers hidden inside everyday objects, each dedicated to performing one specific job.</p>
<p data-narration-id="n3">Your washing machine, microwave, car&rsquo;s anti-lock braking system, traffic lights, heart rate monitor, and the thermostat on your central heating all contain embedded systems. In fact, there are estimated to be roughly 30 billion embedded processors in use worldwide &mdash; compared to fewer than 2 billion general-purpose computers. Embedded systems massively outnumber conventional computers.</p>

<h2 data-narration-id="n4">Key Characteristics of Embedded Systems</h2>
<p data-narration-id="n5">Embedded systems share a set of defining characteristics that distinguish them from general-purpose computers. Understanding these is essential for exam questions that ask you to &ldquo;describe the characteristics of&rdquo; or &ldquo;explain why a device is described as an embedded system.&rdquo;</p>

<p data-narration-id="n6"><strong>1. Dedicated function.</strong> An embedded system is designed to perform one specific task. A washing machine controller manages wash cycles; it cannot be used to browse the internet or run a spreadsheet. This is the opposite of a general-purpose computer, which can run many different programs.</p>

<p data-narration-id="n7"><strong>2. Real-time operation.</strong> Most embedded systems must respond to events within a guaranteed time period. A car&rsquo;s anti-lock braking system (ABS) must detect wheel lock-up and release the brakes within milliseconds &mdash; any longer and the response is too late to be useful. This requirement for predictable, guaranteed timing is called <dfn class="term" data-def="Operation in which a system processes inputs and produces outputs within a strictly defined maximum time period.">real-time operation</dfn>.</p>

<p data-narration-id="n8"><strong>3. Low power consumption.</strong> Many embedded systems run on batteries (fitness bands, pacemakers, remote controls) or must run continuously for years without attention (smart meters, industrial sensors). They are designed to use as little power as possible.</p>

<p data-narration-id="n9"><strong>4. Low cost.</strong> Because embedded systems are mass-produced in billions of units (every microwave sold contains one), cost is critical. Embedded processors are simplified, cheap microcontrollers rather than the powerful, expensive chips found in PCs.</p>

<p data-narration-id="n10"><strong>5. Reliability.</strong> An embedded system inside a pacemaker or an aircraft&rsquo;s flight management system must work correctly every time, without crashing. Unlike a PC that can be rebooted when it freezes, many embedded systems run safety-critical or life-critical functions where failure is not acceptable.</p>

<p data-narration-id="n11"><strong>6. Compact size.</strong> Embedded systems must fit inside their host device. A microcontroller in a hearing aid is smaller than a fingernail. Size constraints mean embedded chips are integrated onto a single chip (System on a Chip, or SoC) rather than spread across a motherboard.</p>

<div class="key-fact" data-narration-id="n12" data-revision-tip="Cover this and list five characteristics of embedded systems from memory, writing one real-world example for each.">
  <div class="key-fact-label">Key Fact</div>
  <p>Embedded systems have six key characteristics: <strong>dedicated function</strong> (one specific task), <strong>real-time operation</strong> (guaranteed response time), <strong>low power consumption</strong>, <strong>low cost</strong>, <strong>high reliability</strong> and <strong>compact size</strong>. Contrast each with a general-purpose computer to nail compare questions.</p>
</div>

<h2 data-narration-id="n13">Embedded Systems in Everyday Life</h2>
<p data-narration-id="n14">The following are examples of embedded systems you should be able to describe in detail:</p>

<p data-narration-id="n15"><strong>Washing machine:</strong> The embedded system monitors the wash cycle, reads temperature and drum speed sensors, controls the motor speed, heater and water inlet valve, and advances through the programme stages in the correct order. The user selects a programme; the embedded system handles everything else automatically.</p>

<p data-narration-id="n16"><strong>Traffic light controller:</strong> An embedded system manages traffic signal timing at a junction. It receives input from road sensors (detecting waiting vehicles), processes the current signal state, and outputs the correct sequence of red, amber and green signals to each set of lights &mdash; all in real time to keep traffic flowing safely.</p>

<p data-narration-id="n17"><strong>Fitness band (activity tracker):</strong> Contains embedded sensors (accelerometer, heart rate monitor) and a microcontroller that reads these sensors, calculates steps, distance and heart rate, stores data and transmits it via Bluetooth to a smartphone. Runs on a small battery for days or weeks, so low power consumption is essential.</p>

<p data-narration-id="n18"><strong>Microwave oven:</strong> The embedded system reads the keypad input, drives the display, controls the magnetron (the component that generates microwaves), runs the turntable motor and counts down the timer. When the timer reaches zero it stops the magnetron and sounds the beeper. No user programming is possible &mdash; the functions are fixed in firmware stored in ROM.</p>

<p data-narration-id="n19"><strong>Engine Management Unit (EMU) in a car:</strong> One of the most sophisticated embedded systems in everyday use. It reads dozens of sensors (throttle position, oxygen level in exhaust, engine temperature, crankshaft speed) and makes real-time adjustments to fuel injection timing and quantity, ignition timing and emissions control. A typical modern car may contain over 100 separate embedded systems.</p>

<div class="key-fact" data-narration-id="n20" data-revision-tip="Close this and write two sentences explaining how a washing machine embedded system works, covering its inputs, processing and outputs.">
  <div class="key-fact-label">Key Fact</div>
  <p>Every embedded system follows an <strong>input &rarr; process &rarr; output</strong> cycle. In a washing machine: sensors provide inputs (water temperature, drum speed), the processor makes decisions (increase heater power, change motor speed), and actuators carry out outputs (heater on/off, motor speed signal). This IPO structure appears in many exam questions.</p>
</div>

  </button>
  <div class="collapsible-content"><div class="collapsible-inner">
    <p data-narration-id="n28">Some embedded systems operate in environments where failure could cause serious harm. These are called <dfn class="term" data-def="A system in which failure could result in injury, loss of life or serious damage, requiring extremely high reliability standards.">safety-critical systems</dfn>. Examples include:</p>
    <ul>
      <li data-narration-id="n29"><strong>Pacemakers</strong> &mdash; regulate the heartbeat of patients with heart conditions. A software bug or power failure could be fatal. Pacemakers are tested to an extremely high standard and their firmware is rarely if ever updated in the field.</li>
      <li data-narration-id="n30"><strong>Anti-lock braking systems (ABS)</strong> &mdash; prevent wheels from locking up during hard braking. The ABS microcontroller must respond within milliseconds or the system fails to prevent a skid.</li>
      <li data-narration-id="n31"><strong>Fly-by-wire flight control systems</strong> &mdash; modern passenger aircraft rely on embedded computers to translate pilot inputs into control surface movements. Multiple redundant systems run in parallel so that if one fails, another takes over immediately.</li>
    </ul>
    <p data-narration-id="n32">These safety-critical applications explain why embedded system software is subject to much more rigorous testing and formal verification than typical consumer software. The cost of failure is simply too high to tolerate bugs.</p>

--- CONCLUSION_HTML ---
<h3 data-narration-id="n34">Key Takeaways</h3>
<ul>
  <li data-narration-id="n35">An embedded system is a computer built into a device to perform one dedicated function, usually in real time. Examples include washing machines, traffic light controllers, fitness bands and car engine management units.</li>
  <li data-narration-id="n36">Embedded systems share six characteristics: dedicated function, real-time operation, low power consumption, low cost, high reliability and compact size &mdash; contrasting sharply with general-purpose computers, which are flexible, expensive and power-hungry.</li>
  <li data-narration-id="n37">Safety-critical embedded systems (pacemakers, ABS, fly-by-wire controls) demand extremely high reliability because failure could cause injury or loss of life. They follow an input &rarr; process &rarr; output cycle, reading sensors, making decisions and driving actuators in real time.</li>
</ul>

--- EXAM_TIP_HTML ---
<p data-narration-id="n33">For &ldquo;describe the characteristics of an embedded system&rdquo; questions, aim for at least three characteristics, each with a brief justification &mdash; not just a list. For example: &ldquo;Embedded systems perform a dedicated function, meaning the processor is programmed for one specific task and cannot run general-purpose software.&rdquo; That is one point with development, worth more than a bare list. For compare questions, always explicitly contrast the embedded system with a general-purpose computer: &ldquo;Unlike a general-purpose computer, which can run any installed software, an embedded system is designed to perform a single fixed task.&rdquo;</p>
