--- DESCRIPTION ---
System, application, utility, open-source and specialist software: what each type does and examples of each.

--- CONTENT_HTML ---
<h2 data-narration-id="n1">What Is Software?</h2>
<p data-narration-id="n2"><dfn class="term" data-def="A set of instructions written in a programming language that tells a computer what to do; software cannot be touched, unlike hardware.">Software</dfn> is the set of instructions that tells a computer how to operate. Without software, even the most powerful hardware is useless. Software is divided into two broad categories: system software, which manages the computer itself, and applications software, which carries out tasks for the user. Within these categories there are several important sub-types that IT professionals must be able to identify and explain.</p>

<h2 data-narration-id="n3">System Software</h2>
<p data-narration-id="n4"><dfn class="term" data-def="Software that controls and manages the hardware of a computer and provides a platform on which applications can run; the most important example is the operating system.">System software</dfn> manages and controls the hardware, creating the environment in which applications can run. The most important example of system software is the operating system (OS). The OS handles fundamental tasks: it manages the CPU, allocates RAM to running programs, controls input and output devices, manages the file system, and provides the user interface. Examples include Microsoft Windows, macOS, Linux, Android and iOS. Without an operating system, the user would need to communicate with hardware directly using binary code — the OS provides the bridge.</p>

<p data-narration-id="n5">System software also includes device drivers, which are small programs that allow the operating system to communicate with specific hardware components such as a printer or graphics card. Without the correct driver, a newly connected device will not function. Firmware is another form of system software stored permanently in hardware (for example, the BIOS/UEFI that runs when a computer first starts up, performing a Power-On Self Test before handing control to the OS).</p>

<div class="key-fact" data-narration-id="n6" data-revision-tip="System software manages hardware and runs in the background; applications software carries out tasks for the user. Learn to tell them apart with examples — this distinction is tested in short-answer questions.">
  <div class="key-fact-label">Key Fact</div>
  <p>System software (operating systems, drivers, firmware) manages the hardware and creates the environment for other software to run. Applications software (word processors, browsers, games) performs specific tasks for the user. The key distinction: system software controls the machine; applications software serves the user.</p>
</div>

<h2 data-narration-id="n7">Applications Software</h2>
<p data-narration-id="n8">Applications software (often just called "apps") performs specific tasks that the user wants to accomplish. Word processing software such as Microsoft Word or Google Docs lets users create, edit and format text documents. Spreadsheet software such as Microsoft Excel handles numerical data, formulas and charts. Presentation software such as PowerPoint produces slide-based displays. Web browsers such as Chrome, Firefox and Safari allow users to navigate the internet. Email clients such as Outlook or Thunderbird manage electronic mail. Each application runs on top of the operating system and depends on system software to access the hardware.</p>

<h2 data-narration-id="n9">Utility Software</h2>
<p data-narration-id="n10"><dfn class="term" data-def="A type of system software that performs specific maintenance or optimisation tasks to keep the computer running efficiently and securely.">Utility software</dfn> sits between system and application software: it maintains and optimises the computer rather than performing a user-facing task. Examples include anti-malware software (which scans for and removes malicious programs), disk defragmenters (which rearrange fragmented data on a hard drive to speed up access), file compression tools (which reduce file sizes for storage and transfer), backup software (which automatically copies important data to a second location), and disk cleanup tools (which delete temporary files and free up storage space). Utility software typically runs in the background or is triggered when maintenance is needed.</p>

  <div class="collapsible-content"><div class="collapsible-inner">
    <p data-narration-id="n11">Businesses rely on computers running continuously and reliably. Utility software maintains this reliability in several ways: anti-malware tools protect against ransomware attacks that could lock the business out of its own files; backup software ensures that a recent copy of critical data exists if hardware fails; file compression reduces the storage space and bandwidth needed to share large files between offices; and disk cleanup tools prevent the gradual slowdown that occurs as temporary files accumulate. IT support professionals configure utility software to run automatically — for example, scheduling a full anti-malware scan each night and an incremental backup every hour — so the business keeps running without interruption.</p>
  </div></div>
</div>

<h2 data-narration-id="n12">Information-Handling Software</h2>
<p data-narration-id="n13">Information-handling software helps organisations collect, store, organise and retrieve large amounts of data. Database management systems (DBMS) such as Microsoft Access or MySQL allow users to create structured databases, run queries to find specific records and generate reports. A school uses a DBMS to store student records, timetables and attendance data; a hospital uses one to manage patient records and appointment scheduling. Spreadsheet software can also be used for simpler information-handling tasks such as budgeting or stock tracking. The defining feature of information-handling software is that it is designed around structured data — rows, columns and relationships between tables.</p>

<h2 data-narration-id="n14">Open-Source Software</h2>
<p data-narration-id="n15"><dfn class="term" data-def="Software whose source code is made freely available to the public, allowing anyone to view, modify and distribute it.">Open-source software</dfn> is software whose source code — the underlying programming instructions — is published so that anyone can view, modify and redistribute it. Linux is the most prominent open-source operating system; LibreOffice is a free, open-source alternative to Microsoft Office. Open-source software has several advantages: it is usually free to download, it benefits from contributions by a global community of developers, and it can be customised to meet specific needs. The main disadvantage is that it may have less formal support than proprietary (closed-source) software, and not all open-source projects are equally well maintained. Many businesses choose a mix: using open-source tools where they are mature and well supported, and commercial proprietary software where reliability and dedicated support are essential.</p>

<div class="key-fact" data-narration-id="n16" data-revision-tip="Remember open-source means the source code is publicly available and free to modify. The opposite is proprietary (closed-source) software, which is owned by a company and cannot be legally altered.">
  <div class="key-fact-label">Key Fact</div>
  <p>Open-source software: source code is public, free to use and modify (e.g. Linux, LibreOffice, Firefox). Proprietary software: source code is private, owned by a company, usually requires a licence fee (e.g. Windows, Microsoft Office, Photoshop). Both types have advantages and disadvantages.</p>
</div>

<h2 data-narration-id="n17">Communication Software</h2>
<p data-narration-id="n18">Communication software enables people to exchange information electronically. Email clients (Outlook, Gmail) send and receive messages and attachments. Video conferencing platforms such as Microsoft Teams and Zoom allow face-to-face meetings over the internet. Instant messaging apps such as WhatsApp or Slack provide real-time text, image and file exchange. Voice over Internet Protocol (VoIP) applications convert voice into data packets and transmit them over the internet, replacing traditional phone calls. Communication software has transformed working practices, enabling remote work, global collaboration and instant customer service without the need for physical presence.</p>

<h2 data-narration-id="n19">Specialist Software</h2>
<p data-narration-id="n20"><dfn class="term" data-def="Software designed for a specific professional or industry purpose, rather than for general everyday use.">Specialist software</dfn> is designed for a particular professional context. Examples include computer-aided design (CAD) software used by architects and engineers to create precise technical drawings; music production software (digital audio workstations such as Logic Pro or Ableton Live) used by music producers; medical imaging software that analyses scan data; point-of-sale (POS) software used by retailers to process transactions; and legal case management software used by solicitors to track client files and deadlines. Specialist software is typically more expensive than general applications because it is developed for a narrower market with specific requirements, and it usually requires specialist training to use.</p>

  <button class="collapsible-toggle" aria-expanded="false">
    <span>How should a business choose between general applications software and specialist software?</span>
    <svg class="collapsible-icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><polyline points="6 9 12 15 18 9"/></svg>

  <div class="collapsible-content"><div class="collapsible-inner">
    <p data-narration-id="n21">The decision comes down to fit and cost. General applications software — a spreadsheet, for instance — can be adapted for many tasks and is cheap or already available on most machines. However, it may require significant manual effort to track complex, industry-specific workflows and it is not optimised for those tasks. Specialist software is built around a specific workflow, which reduces errors, saves time and provides features that a general tool simply does not have — for example, a CAD package handles complex 3D geometry that a word processor or spreadsheet cannot. The cost is justified if the efficiency gains are larger than the licence, training and maintenance fees. An IT consultant advising a client will weigh up the volume of relevant tasks, the skill level of staff, the budget, and whether an open-source alternative exists before making a recommendation.</p>
  </div></div>
</div>

--- CONCLUSION_HTML ---
<h3 data-narration-id="n23">Key Takeaways</h3>
<ul>
  <li data-narration-id="n24">System software (operating system, drivers, firmware) manages the hardware and creates the platform for other software; applications software performs user-facing tasks.</li>
  <li data-narration-id="n25">Utility software maintains and optimises the computer (anti-malware, backup, file compression, disk cleanup); information-handling software organises and retrieves structured data (databases, spreadsheets).</li>
  <li data-narration-id="n26">Open-source software (Linux, LibreOffice) makes its source code publicly available and is free to modify; proprietary software keeps its source code private and usually requires a licence.</li>
  <li data-narration-id="n27">Communication software (email, video conferencing, VoIP) enables electronic exchange of information; specialist software is designed for a specific professional purpose (CAD, music production, POS systems).</li>
</ul>

--- EXAM_TIP_HTML ---
<p data-narration-id="n22">The most common mistake in software questions is confusing system software with utility software. Remember: the operating system is system software — it manages the entire machine; a disk defragmenter or anti-malware tool is utility software — it maintains and optimises the machine. When a question asks you to classify a piece of software, state the category clearly and justify it with a brief explanation of what the software does and for whom. In extended-answer questions comparing open-source and proprietary software, always cover both advantages and disadvantages for each type, and link your points to a realistic context (e.g. a small charity choosing LibreOffice to avoid licence costs).</p>
