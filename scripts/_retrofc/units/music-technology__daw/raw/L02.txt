<h2 data-narration-id="n1">Working Inside a DAW</h2>
<p data-narration-id="n2">Once your hardware is set up, the real work happens inside the DAW software. This lesson covers the key software functions you need to know: project configuration, track types, software instruments, editing, automation, processing plug-ins and exporting.</p>

<h2 data-narration-id="n3">DAW Types & Project Configuration</h2>
<p data-narration-id="n4">DAWs come in two main types: <strong>cloud-based</strong> (run in a web browser, e.g. BandLab, Soundtrap) and <strong>desktop</strong> (installed on your computer, e.g. Logic Pro, Ableton Live, FL Studio). Desktop DAWs generally offer more features and processing power.</p>
<p data-narration-id="n5">When starting a new project, you must configure several settings:</p>
<ul>
<li data-narration-id="n6"><strong>Opening or creating a project</strong> — start from scratch or use a <dfn class="term" data-def="A pre-configured project with tracks, instruments and settings already set up, used as a starting point.">template</dfn> with tracks and instruments pre-loaded.</li>
<li data-narration-id="n7"><strong>Bit depth</strong> — determines the dynamic range of the audio. 16-bit is CD quality; 24-bit is standard for professional recording because it captures a wider dynamic range.</li>
<li data-narration-id="n8"><strong>Sample rate</strong> — the number of audio snapshots taken per second. 44.1 kHz is CD quality; 48 kHz and 96 kHz offer higher fidelity. Higher sample rates create larger files.</li>
<li data-narration-id="n9"><dfn class="term" data-def="A temporary memory store that holds audio data before processing. A larger buffer reduces glitches but increases latency.">Buffer size</dfn> — controls how much audio data is held in memory before processing. A small buffer is best for recording (low <dfn class="term" data-def="The delay between an audio signal entering the system and being heard at the output.">latency</dfn> — minimal delay) while a larger buffer is better for mixing (stable processing, fewer glitches).</li>
<li data-narration-id="n10"><strong>Folders, saving and shortcuts</strong> — organise projects into folders, save regularly, and use keyboard shortcuts (copy, paste, cut, save, undo) for efficient workflow.</li>
<li data-narration-id="n11"><strong>Tempo and time signature</strong> — set the BPM (beats per minute) and time signature (e.g. 4/4, 3/4) to match the music.</li>
</ul>

<div class="key-fact" data-narration-id="n12" data-revision-tip="Cover this and recall: what is buffer size and when would you use a small vs large buffer?">
  <div class="key-fact-label">Key Fact</div>
  <p>Buffer size controls the trade-off between latency and stability. Use a small buffer when recording (low latency so the performer hears themselves in real time) and a larger buffer when mixing (stable processing with more plug-ins).</p>
</div>

<h2 data-narration-id="n13">Track Types</h2>
<p data-narration-id="n14">DAWs offer three main track types:</p>
<ul>
<li data-narration-id="n15"><strong>Audio tracks</strong> — record and play back audio signals. You set the input (which interface channel) and output (where the sound goes), and choose mono (one channel, e.g. a single mic) or stereo (two channels, e.g. a keyboard).</li>
<li data-narration-id="n16"><strong>Software instrument tracks</strong> — host virtual instruments inside the DAW. You play them via MIDI and the software generates the audio.</li>
<li data-narration-id="n17"><strong>MIDI tracks</strong> — record and play MIDI data that is routed to external hardware instruments or internal software instruments. You set the MIDI input (controller) and output (destination instrument).</li>
</ul>

    <svg class="collapsible-icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><polyline points="6 9 12 15 18 9"/></svg>

  <div class="collapsible-content"><div class="collapsible-inner">
    <p data-narration-id="n18"><dfn class="term" data-def="Virtual instruments that run inside a DAW, generating sound from MIDI input without physical hardware.">Software instruments</dfn> fall into two categories: <strong>synth presets</strong> (pre-made sounds from virtual synthesisers) and <strong>sampler presets</strong> (recorded audio samples mapped across a keyboard). Synth editing allows you to adjust the <strong>envelope</strong> (attack, decay, sustain, release), <strong>filter</strong> (brightness/darkness) and <strong>waveform</strong> (the basic shape of the sound). Sampler editing lets you import samples, map them to different keys and set loop points.</p>
    <p data-narration-id="n19"><dfn class="term" data-def="Pre-recorded audio or MIDI patterns that can be repeated and combined to build a track.">Loops</dfn> are pre-recorded audio or MIDI patterns designed to repeat seamlessly. Audio loops are fixed recordings, while MIDI loops can be edited (change notes, tempo, instruments). Loops speed up production by providing ready-made rhythms, bass lines and melodies.</p>
  </div></div>
</div>

<h2 data-narration-id="n20">Editing</h2>
<p data-narration-id="n21">Editing is where you shape and refine your recordings. The DAW provides separate editing tools for MIDI and audio.</p>

<div class="collapsible">
  <button class="collapsible-toggle" aria-expanded="false">
    <span>MIDI & Audio Editing Tools</span>
    <svg class="collapsible-icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><polyline points="6 9 12 15 18 9"/></svg>
  </button>
  <div class="collapsible-content"><div class="collapsible-inner">
    <p data-narration-id="n22"><strong>MIDI editing:</strong> You view notes on a <strong>pitch/rhythm grid</strong> (piano roll) and can cut, copy, paste and move them freely. <dfn class="term" data-def="A DAW function that snaps MIDI notes to the nearest rhythmic grid position, correcting timing imperfections.">Quantise</dfn> snaps notes to the grid to correct timing — with options for <strong>swing</strong> (a subtle rhythmic groove) and <strong>humanisation</strong> (small random variations to avoid a mechanical feel). You can also edit <strong>velocity</strong> (how hard a note is played), <strong>pitch bend</strong> and <strong>controller data</strong> (e.g. modulation wheel, sustain pedal).</p>
    <p data-narration-id="n23"><strong>Audio editing:</strong> Key operations include <strong>trim</strong> (cutting unwanted sections), <strong>copy and paste</strong>, <strong>reverse</strong> (playing audio backwards), <strong>time stretch</strong> (changing length without affecting pitch) and <strong>pitch manipulation</strong> (changing pitch without affecting length).</p>
  </div></div>
</div>



<h2 data-narration-id="n24">Automation</h2>
<p data-narration-id="n25"><dfn class="term" data-def="The process of recording parameter changes over time so the DAW plays them back automatically during playback.">Automation</dfn> lets you record changes to parameters over time. Instead of manually adjusting a fader during playback, you draw or record the movement and the DAW replays it automatically. You can automate <strong>volume</strong>, <strong>pan</strong> (left/right positioning), <strong>instrument parameters</strong> and <strong>plug-in parameters</strong> (e.g. filter cutoff, reverb level).</p>

<h2 data-narration-id="n26">Processing Plug-ins</h2>
<p data-narration-id="n27">Plug-ins are software effects that process audio in real time. The main categories are:</p>
<ul>
<li data-narration-id="n28"><strong>Effects</strong> — <dfn class="term" data-def="An effect that simulates the reflections of sound in a physical space, adding depth and ambience.">reverb</dfn> (simulates room reflections) and <strong>delay</strong> (repeats the signal after a time gap).</li>
<li data-narration-id="n29"><strong>Modulation</strong> — <strong>chorus</strong> (thickens sound by layering slightly detuned copies), <strong>flanging</strong> (sweeping comb filter) and <strong>phasing</strong> (shifting phase relationship).</li>
<li data-narration-id="n30"><strong>Filter</strong> — <strong>wah-wah</strong> (sweeps a bandpass filter for an expressive effect).</li>
<li data-narration-id="n31"><strong>Distortion</strong> — <strong>amp simulation</strong> (models guitar amplifiers) and <strong>overdrive</strong> (warm, mild clipping).</li>
<li data-narration-id="n32"><strong>EQ</strong> — adjusts specific frequency bands. Controls include low/high pass filters, frequency selection, <strong>Q</strong> (bandwidth), gain and <dfn class="term" data-def="Reducing the level of a specific frequency band using an equaliser.">attenuation</dfn>.</li>
<li data-narration-id="n33"><strong>Dynamics</strong> — <strong>compressor</strong> (reduces dynamic range), <strong>limiter</strong> (prevents signal exceeding a threshold) and <strong>gate</strong> (silences audio below a threshold). Key parameters: threshold, ratio, attack, release and gain.</li>
</ul>

<div class="key-fact" data-narration-id="n34" data-revision-tip="Test yourself: name the four key parameters of a compressor and explain what each controls.">
  <div class="key-fact-label">Key Fact</div>
  <p>A compressor’s four key parameters are: threshold (the level above which compression starts), ratio (how much the signal is reduced), attack (how quickly compression kicks in) and release (how quickly it stops). Gain compensates for volume lost during compression.</p>
</div>

<h2 data-narration-id="n35">Exporting</h2>
<p data-narration-id="n36">When a project is complete, you <strong>export</strong> (also called “bounce”) it to a stereo audio file. You can export the entire project or individual parts. Export settings include <strong>bit depth</strong>, <strong>sample rate</strong> and <strong>file format</strong>: WAV and AIF are uncompressed (high quality, large files), while MP3 is compressed (smaller file, some quality loss).</p>

--- CONCLUSION_HTML ---
<h3 data-narration-id="n38">Key Takeaways</h3>
<ul>
<li data-narration-id="n39">Configure projects with the right bit depth, sample rate, buffer size, tempo and time signature before recording.</li>
<li data-narration-id="n40">MIDI editing uses quantise, velocity and pitch bend; audio editing uses trim, time stretch and pitch manipulation.</li>
<li data-narration-id="n41">Processing plug-ins include effects (reverb, delay), modulation (chorus, flanger, phaser), EQ, dynamics (compressor, limiter, gate) and distortion.</li>
</ul>
