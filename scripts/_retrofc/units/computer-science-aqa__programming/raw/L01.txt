<h2 data-narration-id="n1">Why Data Types Matter</h2>
<p data-narration-id="n2">Every piece of data stored in a program has a <dfn class="term" data-def="A classification that tells the computer what kind of data is being stored, how much memory to allocate, and what operations are valid on it.">data type</dfn>. Choosing the right type is not just a technical formality &mdash; it determines what you can do with the data. You cannot multiply two text strings. You cannot store the word &ldquo;open&rdquo; as a Boolean. Getting the type wrong leads to errors that are often hard to diagnose. The specification names five data types you must know.</p>

<div class="key-fact" data-narration-id="n3" data-revision-tip="Cover this and list all five data types from the specification with one example value for each.">
  <div class="key-fact-label">Key Fact</div>
  <p>The five data types are: <strong>integer</strong> (whole number, e.g. 7 or &minus;3), <strong>real</strong> (number with a decimal point, e.g. 3.14 or &minus;0.5), <strong>Boolean</strong> (true or false only), <strong>character</strong> (a single symbol, e.g. &lsquo;A&rsquo; or &lsquo;?&rsquo;), and <strong>string</strong> (a sequence of characters, e.g. &ldquo;hello&rdquo; or &ldquo;12 Oak Road&rdquo;).</p>
</div>

<h2 data-narration-id="n4">The Five Data Types</h2>
<p data-narration-id="n5">An <dfn class="term" data-def="A whole number with no decimal part, which can be positive, negative or zero.">integer</dfn> stores a whole number. Examples: a person&rsquo;s age, a score in a game, the number of students in a class. Integers support the full range of arithmetic operations.</p>
<p data-narration-id="n6">A <dfn class="term" data-def="A number that can include a decimal point, sometimes called a floating-point number in specific programming languages.">real</dfn> number stores values that can have a fractional part. Examples: a temperature reading (36.7), a price (&pound;12.99), a percentage (78.5). Some languages call this type &lsquo;float&rsquo; &mdash; but in your exam you should use the term &lsquo;real&rsquo;.</p>
<p data-narration-id="n7">A <dfn class="term" data-def="A data type that can hold only one of two values: true or false.">Boolean</dfn> holds only one of two values: true or false. Examples: whether a light is on or off, whether a user is logged in, whether a password matches. Boolean conditions are central to all selection and iteration.</p>
<p data-narration-id="n8">A <dfn class="term" data-def="A data type that holds exactly one symbol, such as a letter, digit or punctuation mark.">character</dfn> stores exactly one symbol &mdash; a letter, digit, space or punctuation mark. Stored in single quotes: &lsquo;A&rsquo;, &lsquo;9&rsquo;, &lsquo;!&rsquo;. A <dfn class="term" data-def="A data type that holds a sequence of zero or more characters, used to store text such as names, addresses and messages.">string</dfn> is a sequence of characters of any length, including zero (an empty string). Stored in double quotes: &ldquo;hello&rdquo;, &ldquo;password123&rdquo;, &ldquo;&rdquo; (empty).</p>

<h2 data-narration-id="n10">Variables and Constants</h2>
<p data-narration-id="n11">A <dfn class="term" data-def="A named storage location in memory that holds a value which can be changed during program execution.">variable</dfn> is a named location in memory whose value can change while the program runs. In AQA pseudo-code, you declare and assign a variable in one step: <code>score &larr; 0</code>. Every variable has a name (its <em>identifier</em>), a value, and a data type.</p>
<p data-narration-id="n12">A <dfn class="term" data-def="A named value that is assigned once and cannot be changed during program execution, often written in uppercase to distinguish it from variables.">constant</dfn> is similar, but its value is fixed for the entire program. Example: <code>MAX_ATTEMPTS &larr; 3</code>. Constants are typically written in uppercase to signal that their value must not be changed. Using named constants makes code easier to maintain &mdash; if you need to change the maximum number of login attempts from 3 to 5, you change it in one place rather than finding every occurrence of the number 3 in your code.</p>

<div class="key-fact" data-narration-id="n13" data-revision-tip="Test yourself: Explain why meaningful identifier names matter. Give one example of a bad name and one good name for a variable that stores a student's exam score.">
  <div class="key-fact-label">Key Fact</div>
  <p>Meaningful <strong>identifier names</strong> make code readable and maintainable. <code>examScore</code> is immediately clear; <code>x</code> or <code>temp123</code> is not. In your exam, examiners expect you to use meaningful names when writing programs or pseudo-code. Using single-letter variables (other than conventional loop counters like <code>i</code>) will cost marks on programming questions.</p>
</div>

<h2 data-narration-id="n14">The Three Programming Constructs</h2>
<p data-narration-id="n15">Every program, regardless of language, is built from three fundamental constructs: <dfn class="term" data-def="The programming construct in which instructions are executed one after another in the order they are written.">sequence</dfn>, <dfn class="term" data-def="The programming construct in which the program chooses between different execution paths based on a condition.">selection</dfn>, and <dfn class="term" data-def="The programming construct in which a block of instructions is repeated, either a fixed number of times or while a condition is true.">iteration</dfn>. These are the only three building blocks needed to solve any computable problem.</p>

<h2 data-narration-id="n22">DIV and MOD Operators</h2>
<p data-narration-id="n23">Two arithmetic operators you must know are <code>DIV</code> and <code>MOD</code>. <code>DIV</code> performs integer division and returns the whole-number quotient. <code>MOD</code> returns the remainder. For example: 17 <code>DIV</code> 5 gives 3 (because 5 goes into 17 three full times). 17 <code>MOD</code> 5 gives 2 (because 17 = 3 &times; 5 + 2). These operators appear frequently in exam questions because they are used to test whether a number is odd or even (<code>n MOD 2 = 0</code> means even), to extract individual digits, and to create circular patterns in data structures.</p>

--- CONCLUSION_HTML ---
<h3 data-narration-id="n25">Key Takeaways</h3>
<ul>
  <li data-narration-id="n26">The five data types are integer (whole number), real (decimal), Boolean (true/false), character (single symbol) and string (sequence of characters). Use &lsquo;real&rsquo; not &lsquo;float&rsquo; in your exam.</li>
  <li data-narration-id="n27">Variables hold changeable values; constants hold fixed values. Both need meaningful identifier names so code is readable and maintainable.</li>
  <li data-narration-id="n28">Every program is built from three constructs: sequence (in order), selection (conditional branches) and iteration (repetition). DIV gives integer division; MOD gives the remainder.</li>
</ul>

--- EXAM_TIP_HTML ---
<p data-narration-id="n24">When a question asks you to declare a variable or assign a value, always state the data type or use it correctly in context. A common error is performing arithmetic on a string &mdash; if a question says &lsquo;the user enters a number&rsquo;, assume the input arrives as a string and will need converting before arithmetic. For &lsquo;meaningful identifier names&rsquo; questions, show that your name clearly describes the variable&rsquo;s purpose &mdash; examiners will deduct marks for single-letter names except conventional loop counters.</p>
