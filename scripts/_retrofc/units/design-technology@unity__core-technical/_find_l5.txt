A <dfn class="term" data-def="A linkage that passes a push or a pull straight through, so the output moves in the same direction as the input.">push/pull linkage</dfn> keeps the output moving the same way as the input — push one end and the other end pushes out. A reverse-motion linkage does the opposite: push one end and the other end pulls back.
