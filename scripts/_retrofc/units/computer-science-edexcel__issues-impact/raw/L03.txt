--- DESCRIPTION ---
How malware and social engineering attack systems, and the five protections that defend them.

--- CONTENT_HTML ---
<h2 data-narration-id="n1">Why Cybersecurity Matters</h2>
<p data-narration-id="n2"><dfn class="term" data-def="The processes, practices and technologies designed to protect networks, computers, programs and data from attack, damage or unauthorised access.">Cyber security</dfn> is the field concerned with defending digital systems and data from attack. It affects everyone: a hospital storing patient records, a bank holding millions of account details, a school with pupil data, and an individual with a social media profile. Cyber threats do not require physical proximity &mdash; an attacker can target systems from anywhere in the world, which is what makes them so difficult to defend against.</p>
<p data-narration-id="n3">Threats come from two broad directions. Some exploit technical weaknesses in software or networks. Others exploit the most unpredictable part of any system: the people using it. Understanding how attacks work is the first step towards building effective defences.</p>

<h2 data-narration-id="n4">Malware: The Five Types</h2>
<p data-narration-id="n5"><dfn class="term" data-def="An umbrella term for any software that is hostile, intrusive or designed to damage, disrupt or gain unauthorised access to a computer system.">Malware</dfn> (malicious software) is any program designed to cause harm. There are five types you need to know for your exam.</p>

<div class="collapsible">
  <button class="collapsible-toggle" aria-expanded="false">
    <span>The Five Types of Malware</span>
    <svg class="collapsible-icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><polyline points="6 9 12 15 18 9"/></svg>
  </button>
  <div class="collapsible-content"><div class="collapsible-inner">
    <p data-narration-id="n6">A <dfn class="term" data-def="A type of malware that attaches itself to legitimate files and spreads by copying itself when an infected file is opened or shared.">computer virus</dfn> attaches to an existing file or program. When the infected file is opened or shared &mdash; for example, via an email attachment or a USB drive &mdash; the virus copies itself to other files. Viruses require a host file and rely on user action to spread.</p>
    <p data-narration-id="n7">A <dfn class="term" data-def="A type of malware that spreads automatically across networks without needing to attach to a file or require user action, exploiting security vulnerabilities to replicate itself.">worm</dfn> is similar to a virus but does not need a host file. It spreads automatically across networks by exploiting security vulnerabilities, with no user action required. A single unpatched device on a network can allow a worm to propagate to every connected machine.</p>
    <p data-narration-id="n8">A <dfn class="term" data-def="Malware disguised as legitimate software that, once installed, opens a back door allowing an attacker to access the system remotely, without self-replicating.">trojan</dfn> (or trojan horse) disguises itself as useful software &mdash; a free game, a codec update, a utility. Once installed, it operates silently, typically opening a back door that gives an attacker remote access. Unlike a virus or worm, a trojan does not self-replicate.</p>
    <p data-narration-id="n9"><dfn class="term" data-def="Malware that encrypts a victim's files and demands a payment, typically in cryptocurrency, in exchange for the decryption key.">Ransomware</dfn> encrypts the victim&rsquo;s files, making them inaccessible, and then demands a ransom payment in exchange for the decryption key. High-profile ransomware attacks have targeted hospitals, councils and businesses. Even paying the ransom does not guarantee that files will be restored.</p>
    <p data-narration-id="n10">A <dfn class="term" data-def="A type of spyware that secretly records every keystroke made on a device, capturing passwords, bank details and messages, and transmits the data to an attacker.">key logger</dfn> is a form of spyware that runs hidden in the background and records every key pressed on the device. Passwords, bank account details, messages and search terms are all captured. The collected data is transmitted back to the attacker without the user&rsquo;s knowledge.</p>
  </div></div>
</div>

<div class="key-fact" data-narration-id="n11" data-revision-tip="Cover this and write a one-sentence description of each malware type, making sure you include its key distinguishing feature.">
  <div class="key-fact-label">Key Fact</div>
  <p>Five malware types: <strong>virus</strong> (attaches to files, needs user action to spread), <strong>worm</strong> (spreads automatically across networks, no host file needed), <strong>trojan</strong> (disguised as legitimate software, opens a back door), <strong>ransomware</strong> (encrypts files and demands payment), <strong>key logger</strong> (records keystrokes silently).</p>
</div>

<h2 data-narration-id="n12">Technical Vulnerabilities</h2>
<p data-narration-id="n13">Hackers do not always need sophisticated malware &mdash; they can exploit weaknesses that organisations have failed to close. The two main technical vulnerabilities in this specification are <dfn class="term" data-def="Software that has not had available security fixes applied, leaving known vulnerabilities that attackers can exploit.">unpatched software</dfn> and out-of-date anti-malware.</p>
<p data-narration-id="n14">When a software vulnerability is discovered, the developer releases a security patch &mdash; an update that closes the gap. Systems that have not applied the patch remain exposed. Attackers can find published details of known vulnerabilities and write code to exploit them. This is why applying software updates promptly matters: the update often closes a door that attackers are already trying to walk through. Similarly, <dfn class="term" data-def="Software that detects and removes malicious programs by comparing files and behaviour against a database of known threats and suspicious patterns.">anti-malware software</dfn> that has not been updated cannot recognise the latest threats, leaving newer malware able to operate undetected.</p>

<h2 data-narration-id="n15">Social Engineering</h2>
<p data-narration-id="n16"><dfn class="term" data-def="The manipulation of people into giving up confidential information or taking actions that compromise security, by exploiting trust and psychological pressure rather than technical vulnerabilities.">Social engineering</dfn> targets human psychology rather than technical flaws. Attackers create believable scenarios or apply pressure to trick people into doing something that compromises security &mdash; revealing a password, clicking a link, or transferring money. Three forms appear in the specification.</p>

<div class="collapsible">
  <button class="collapsible-toggle" aria-expanded="false">
    <span>Phishing, Pretexting and Shouldering</span>
    <svg class="collapsible-icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><polyline points="6 9 12 15 18 9"/></svg>
  </button>
  <div class="collapsible-content"><div class="collapsible-inner">
    <p data-narration-id="n17"><dfn class="term" data-def="A social engineering attack using fraudulent emails, text messages or fake websites to trick users into revealing passwords, bank details or other private information.">Phishing</dfn> arrives as an email or text message that appears to come from a trusted source &mdash; a bank, a delivery company, or a well-known service. It typically creates urgency (&ldquo;Your account will be suspended unless you act now&rdquo;) and directs the target to a fake website to harvest credentials. Spear phishing is a targeted variant aimed at a specific individual, using personalised details to make the deception more convincing.</p>
    <p data-narration-id="n18"><dfn class="term" data-def="A social engineering technique in which an attacker creates a fabricated scenario to manipulate a target into revealing information or performing an action.">Pretexting</dfn> (sometimes called blagging) involves inventing a convincing story to gain access or information. An attacker might call a company helpdesk claiming to be an IT contractor who urgently needs a user&rsquo;s credentials reset, or pose as a supplier requesting bank account details. The invented scenario creates a sense of authority or urgency that overrides the target&rsquo;s normal caution.</p>
    <p data-narration-id="n19"><dfn class="term" data-def="Observing a person's private information over their shoulder, for example watching someone enter a PIN at a cashpoint or reading a password as it is typed.">Shouldering</dfn> (shoulder surfing) is the simplest form of social engineering: physically watching someone enter private information. It can happen at cashpoints, on public transport, or in shared workspaces where someone observes a colleague typing a password or reading a confidential document.</p>
  </div></div>
</div>

<h2 data-narration-id="n20">The Five Protections</h2>
<p data-narration-id="n21">Defending digital systems requires a layered approach. Five specific protection methods are named in the specification: anti-malware software, encryption, acceptable use policies, backup, and recovery procedures. Together these form a defence strategy that addresses different points of failure.</p>

<div class="collapsible">
  <button class="collapsible-toggle" aria-expanded="false">
    <span>A Layered Defence Strategy</span>
    <svg class="collapsible-icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><polyline points="6 9 12 15 18 9"/></svg>
  </button>
  <div class="collapsible-content"><div class="collapsible-inner">
    <p data-narration-id="n22"><strong>Anti-malware software</strong> detects and removes malicious programs by comparing files and behaviour against databases of known threats and suspicious patterns. It works best when updated frequently so that definitions include the most recent threats. Anti-malware can catch known viruses, worms and trojans before they execute, and can quarantine suspicious files for review.</p>
    <p data-narration-id="n23"><strong>Encryption</strong> converts data into a scrambled form that can only be read by someone with the correct key. If an attacker intercepts encrypted data in transit or steals an encrypted file, they cannot read its contents without the key. Encryption protects data at rest (stored on a device or server) and in transit (moving across a network).</p>
    <p data-narration-id="n24">An <dfn class="term" data-def="A formal written agreement that sets out the rules governing how employees or users may use an organisation's IT systems, networks and data, and the consequences of misuse.">acceptable use policy (AUP)</dfn> sets out the rules governing how staff may use an organisation&rsquo;s IT systems. It defines what is and is not permitted: which websites may be accessed, whether personal use is allowed, how sensitive data must be handled, and the penalties for misuse. A well-enforced AUP reduces the likelihood of employees accidentally (or deliberately) introducing threats through risky behaviour.</p>
    <p data-narration-id="n25"><strong>Backup</strong> involves regularly copying data to a separate location &mdash; an external drive, a secure server or a cloud service &mdash; so that if the original is lost, corrupted or encrypted by ransomware, the data can be restored. Backups must be frequent enough to limit data loss to an acceptable period and stored in a location not directly accessible from the primary system (to prevent ransomware encrypting the backup too).</p>
    <p data-narration-id="n26"><strong>Recovery procedures</strong> are the documented plans and steps an organisation follows after a successful attack or system failure. They specify who does what, in what order, to restore services and data. Without tested recovery procedures, even organisations with good backups may take much longer than necessary to return to normal operation after an incident.</p>
  </div></div>
</div>

<div class="key-fact" data-narration-id="n27" data-revision-tip="Cover this and name all five protections. For each one, write a sentence describing what it guards against or what it does.">
  <div class="key-fact-label">Key Fact</div>
  <p>The five named protections are: <strong>anti-malware software</strong> (detects and removes malicious programs), <strong>encryption</strong> (scrambles data so it is unreadable without a key), <strong>acceptable use policy</strong> (rules governing how staff use IT systems), <strong>backup</strong> (regularly copies data to a separate location), and <strong>recovery procedures</strong> (documented steps to restore systems after an attack).</p>
</div>

--- CONCLUSION_HTML ---
<h3 data-narration-id="n29">Key Takeaways</h3>
<ul>
  <li data-narration-id="n30">Five malware types: viruses (spread via host files), worms (spread across networks automatically), trojans (disguised as legitimate software), ransomware (encrypts files for ransom), key loggers (record keystrokes silently).</li>
  <li data-narration-id="n31">Hackers also exploit technical vulnerabilities &mdash; unpatched software and out-of-date anti-malware &mdash; and use social engineering (phishing, pretexting, shouldering) to bypass technical defences by targeting people.</li>
  <li data-narration-id="n32">Five layered protections: anti-malware software, encryption, acceptable use policies, backup and recovery procedures. Together they address detection, data confidentiality, user behaviour, data recovery and incident response.</li>
</ul>

--- EXAM_TIP_HTML ---
<p data-narration-id="n28">For questions on malware, be precise about what distinguishes each type: a virus needs a host file; a worm spreads automatically; a trojan disguises itself; ransomware encrypts files; a key logger records keystrokes. Mixing up these definitions costs marks. For questions on protections, the specification lists exactly five &mdash; anti-malware, encryption, acceptable use policies, backup and recovery procedures. Do not add others (firewalls, biometrics, two-factor authentication are not in this list). For <strong>Discuss</strong> questions, always cover both the threat landscape and the limitations of any protection &mdash; for example, anti-malware cannot detect threats it has not seen before.</p>
