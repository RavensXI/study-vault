<h2 data-narration-id="n1">Primary and Secondary Storage</h2>
<p data-narration-id="n2">Computers use two broad categories of storage. <dfn class="term" data-def="Memory that the CPU can access directly, including RAM, ROM, cache and registers. Also called main memory.">Primary storage</dfn> (also called main memory) is directly accessible by the CPU and is used for data and instructions the computer is currently working with. <dfn class="term" data-def="Persistent storage separate from main memory, used to store files, programs and operating systems when the computer is not actively using them.">Secondary storage</dfn> is separate from main memory and holds data long-term, even when the power is off. The CPU cannot access secondary storage directly &mdash; data must first be loaded into primary storage before the CPU can process it.</p>

<div class="key-fact" data-narration-id="n3" data-revision-tip="Cover this and list the four types of primary storage. Write one key fact about each.">
  <div class="key-fact-label">Key Fact</div>
  <p>The four types of primary storage are: <strong>RAM</strong> (main working memory, volatile), <strong>ROM</strong> (startup instructions, non-volatile), <strong>cache</strong> (fast small memory on or near the CPU) and <strong>registers</strong> (the fastest storage, inside the CPU itself). RAM and ROM are the two you will be asked to compare most often.</p>
</div>

<h2 data-narration-id="n4">Volatile and Non-Volatile Memory</h2>
<p data-narration-id="n5">A critical distinction in storage is whether memory retains its contents without power. <dfn class="term" data-def="Memory that loses all its stored data when the power supply is switched off.">Volatile memory</dfn> is erased when power is cut. <dfn class="term" data-def="Memory that retains its stored data even when the power supply is switched off.">Non-volatile memory</dfn> keeps its contents without power. RAM is volatile; ROM is non-volatile. This is why unsaved work is lost in a power cut &mdash; it exists only in volatile RAM.</p>

<h2 data-narration-id="n6">RAM &mdash; Random Access Memory</h2>
<p data-narration-id="n7"><dfn class="term" data-def="Random Access Memory — volatile primary storage that holds the programs and data the CPU is currently using. Its contents are lost when power is removed.">RAM</dfn> is the computer&rsquo;s main working memory. When you open an application, the operating system copies it from secondary storage into RAM so the CPU can access it quickly. RAM is much faster than any form of secondary storage but loses everything when the computer is switched off.</p>
<p data-narration-id="n8">The amount of RAM affects how many programs can be open at once without slowing down. A computer with more RAM can hold more data in quick-access memory, reducing the need to fetch from slower secondary storage. Modern computers typically have between 8 and 64 GB of RAM.</p>

<h2 data-narration-id="n9">ROM &mdash; Read Only Memory</h2>
<p data-narration-id="n10"><dfn class="term" data-def="Read Only Memory — non-volatile primary storage that contains the startup instructions (firmware) needed to initialise the computer. Its contents cannot be changed by normal programs.">ROM</dfn> stores the firmware instructions that run when the computer first powers on. These instructions initialise the hardware and begin loading the operating system from secondary storage into RAM. ROM is non-volatile and read-only in normal use, so its contents cannot be accidentally overwritten.</p>
<p data-narration-id="n11">ROM is much smaller than RAM &mdash; it needs to hold only the minimal startup code, not entire programs. A computer&rsquo;s ROM might contain just a few megabytes, whereas RAM is measured in gigabytes.</p>

<h2 data-narration-id="n14">Why Is Secondary Storage Needed?</h2>
<p data-narration-id="n15">Secondary storage is essential because RAM is volatile &mdash; switch the computer off and all RAM contents are gone. Secondary storage provides three things that primary storage cannot: <strong>persistence</strong> (files survive when power is off), <strong>capacity</strong> (far more data can be stored, measured in terabytes) and <strong>portability</strong> (storage devices can be moved between computers).</p>
<p data-narration-id="n16">Every file you save, every application installed, and the operating system itself live on secondary storage. When you open a file, it is copied from secondary storage into RAM. When you save, it is written back from RAM to secondary storage.</p>

<div class="key-fact" data-narration-id="n17" data-revision-tip="Close this and explain in two sentences why secondary storage is needed, mentioning capacity, persistence and portability.">
  <div class="key-fact-label">Key Fact</div>
  <p>Secondary storage is needed for three reasons: <strong>capacity</strong> (far more data than RAM can hold), <strong>persistence</strong> (data is retained without power) and <strong>portability</strong> (storage devices can be transported and used in other systems). RAM is fast but temporary; secondary storage is slower but permanent.</p>
</div>

<h2 data-narration-id="n18">Types of Secondary Storage</h2>
<p data-narration-id="n19"><dfn class="term" data-def="Storage that uses magnetic fields to record data on spinning platters (HDD) or magnetic tape. Data is encoded as north/south magnetic poles.">Magnetic storage</dfn> uses magnetic fields to encode data on a surface. Hard disk drives (HDDs) store data on rapidly spinning metal platters coated with a magnetic material. A read/write head moves across the spinning surface to access or record data. Magnetic tape is an older form used for archival backup &mdash; sequential access makes it slow to retrieve specific files but it can store very large amounts at low cost.</p>
<p data-narration-id="n20"><dfn class="term" data-def="Storage that uses electronic flash memory chips with no moving parts. Data is stored as electrical charges in floating-gate transistors.">Solid-state storage</dfn> (SSD) stores data in electronic memory chips with no moving parts. Because nothing physically moves, SSDs are faster, quieter, lighter and more shock-resistant than HDDs. However, SSDs cost more per gigabyte of capacity. Smartphones, tablets and modern laptops commonly use SSDs.</p>

<div class="collapsible">
  <button class="collapsible-toggle" aria-expanded="false">
    <span>SSD vs HDD &mdash; Advantages and Disadvantages</span>

  <div class="collapsible-content"><div class="collapsible-inner">
    <p data-narration-id="n21"><strong>SSD advantages:</strong> Faster access times (no moving parts to position), silent, uses less power, more durable (resistant to physical shock), lighter and more compact.</p>
    <p data-narration-id="n22"><strong>SSD disadvantages:</strong> More expensive per GB, capacity per pound spent is lower than HDD, limited write cycles (though this is not a practical issue for typical usage).</p>
    <p data-narration-id="n23"><strong>HDD advantages:</strong> Lower cost per GB, available in very large capacities (multiple TB), widely available.</p>
    <p data-narration-id="n24"><strong>HDD disadvantages:</strong> Slower access (mechanical parts must physically move to the right position), produces heat and noise, vulnerable to physical shock (head crash), heavier and larger.</p>
  </div></div>
</div>

<h2 data-narration-id="n25">Cloud Storage</h2>
<p data-narration-id="n26"><dfn class="term" data-def="Storing data on remote servers accessed over the internet, rather than on local hardware.">Cloud storage</dfn> means storing files on servers owned and managed by a third party, accessed over the internet. Services such as these are used by millions of people and businesses to back up files, share data across devices and collaborate remotely.</p>
<p data-narration-id="n27"><strong>Advantages of cloud storage:</strong> Files are accessible from any device with internet access, data is backed up automatically (protection against local hardware failure), easy to share files with others, and no physical hardware to manage or replace.</p>
<p data-narration-id="n28"><strong>Disadvantages of cloud storage:</strong> Requires an internet connection to access files, dependent on the service provider remaining operational, raises privacy concerns (data is held by a third party), and ongoing subscription costs can be higher long-term than purchasing local storage. Access can be slower than local storage if internet speeds are limited.</p>

--- CONCLUSION_HTML ---
<h3 data-narration-id="n30">Key Takeaways</h3>
<ul>
  <li data-narration-id="n31">Primary storage: RAM (volatile, holds current programs and data), ROM (non-volatile, holds startup firmware), cache (fast, close to CPU) and registers (fastest, inside CPU). Secondary storage provides capacity, persistence and portability that RAM cannot.</li>
  <li data-narration-id="n32">Secondary storage types: magnetic (HDDs and tape &mdash; moving parts, cheaper per GB, slower); solid-state (no moving parts, faster, more expensive per GB, durable). Both have distinct trade-offs.</li>
  <li data-narration-id="n33">Cloud storage stores files on remote servers accessed over the internet. Advantages include any-device access and automatic backup; disadvantages include internet dependency, privacy concerns and subscription costs.</li>
</ul>

--- EXAM_TIP_HTML ---
<p data-narration-id="n29">RAM vs ROM comparison questions are extremely common. Make sure you know the key contrast: RAM is volatile and read/write; ROM is non-volatile and read-only. For secondary storage questions, you must be able to explain the operation of both solid-state and magnetic storage and compare their advantages and disadvantages &mdash; not just name them. For cloud storage, always give both sides when asked to &ldquo;discuss&rdquo; or &ldquo;evaluate&rdquo;: accessibility and automatic backup are advantages; internet dependency, privacy concerns and cost are disadvantages. When a question asks why secondary storage is needed, use the three-word answer: capacity, persistence, portability.</p>
