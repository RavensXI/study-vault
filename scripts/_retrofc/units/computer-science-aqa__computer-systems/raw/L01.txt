<h2 data-narration-id="n1">What Is Boolean Logic?</h2>
<p data-narration-id="n2"><dfn class="term" data-def="A branch of algebra dealing only with values that are true (1) or false (0), using operators such as AND, OR, NOT and XOR.">Boolean logic</dfn> underpins all digital computing. Inside a processor, every decision reduces to combinations of 1s and 0s. Logic gates are the physical building blocks that implement Boolean operations in hardware &mdash; they take binary inputs and produce a binary output according to a defined rule.</p>
<p data-narration-id="n3">You must know four logic gates for your exam: <strong>NOT</strong>, <strong>AND</strong>, <strong>OR</strong> and <strong>XOR</strong>. A <dfn class="term" data-def="A table that lists every possible combination of inputs for a logic gate or circuit and the corresponding output for each combination.">truth table</dfn> is the standard way to show how any gate or combination of gates behaves &mdash; it lists every possible set of input values and the resulting output.</p>

<h2 data-narration-id="n4">The Four Logic Gates</h2>
<p data-narration-id="n5">The <dfn class="term" data-def="A logic gate that reverses its input: a 1 input produces a 0 output, and a 0 input produces a 1 output.">NOT gate</dfn> has a single input and inverts it. If the input is 1, the output is 0; if the input is 0, the output is 1. It is sometimes called an inverter. In Boolean notation, NOT A is written with an overbar: &Acirc;.</p>
<p data-narration-id="n6">The <dfn class="term" data-def="A logic gate that outputs 1 only when all of its inputs are 1.">AND gate</dfn> outputs 1 only when every input is 1. If any input is 0, the output is 0. In Boolean notation, A AND B is written as A &middot; B (a dot). Think of it as: both conditions must be true.</p>
<p data-narration-id="n7">The <dfn class="term" data-def="A logic gate that outputs 1 when at least one of its inputs is 1.">OR gate</dfn> outputs 1 when at least one input is 1. It outputs 0 only when every input is 0. In Boolean notation, A OR B is written as A + B (a plus sign). Think of it as: at least one condition is true.</p>
<p data-narration-id="n8">The <dfn class="term" data-def="Exclusive OR gate — outputs 1 only when exactly one of its inputs is 1, not when both are 1.">XOR gate</dfn> (exclusive OR) outputs 1 when exactly one of its inputs is 1 &mdash; but not when both are 1. This is what makes XOR different from OR: OR is true when one OR both inputs are true; XOR is true when one input is true but NOT both. In Boolean notation, A XOR B is written as A &oplus; B.</p>

<div class="key-fact" data-narration-id="n9" data-revision-tip="Cover this and draw the complete truth table for XOR from memory, including the case where both inputs are 1.">
  <div class="key-fact-label">Key Fact</div>
  <p>XOR outputs 1 only when inputs differ (one is 0, the other is 1). When both inputs are the same (both 0 or both 1), XOR outputs 0. This is the key distinction from OR, which outputs 1 when both inputs are 1.</p>
</div>

<h2 data-narration-id="n15">Boolean Notation</h2>
<p data-narration-id="n16">Your exam uses a specific set of symbols for Boolean expressions. You must recognise and use them correctly:</p>
<ul>
  <li data-narration-id="n17"><strong>A &middot; B</strong> means A AND B (a dot between variables).</li>
  <li data-narration-id="n18"><strong>A + B</strong> means A OR B (a plus sign between variables).</li>
  <li data-narration-id="n19"><strong>A &oplus; B</strong> means A XOR B (a circled plus sign).</li>
  <li data-narration-id="n20"><strong>&Acirc;</strong> (A with an overbar above it) means NOT A.</li>
</ul>
<p data-narration-id="n21">So the expression (A AND B) OR (NOT C) is written as: <strong>A &middot; B + &Ccedil;</strong>. Always evaluate brackets first, just as in ordinary arithmetic.</p>

<h2 data-narration-id="n22">Truth Tables with Three Inputs</h2>
<p data-narration-id="n23">When a circuit has three inputs (A, B, C), the truth table needs 2<sup>3</sup> = 8 rows to cover every combination. List the input columns in a consistent binary counting pattern so no combination is missed:</p>

    <p data-narration-id="n24"><strong>Expression:</strong> (A AND B) OR (NOT C) &mdash; written as A &middot; B + &Ccedil;</p>
    <p data-narration-id="n25">Add an intermediate column for A &middot; B, then a column for NOT C, then combine with OR for the final output.</p>
    <p data-narration-id="n26">Row 1: A=0,B=0,C=0 &mdash; A&middot;B=0, NOT C=1, Output=1<br>
Row 2: A=0,B=0,C=1 &mdash; A&middot;B=0, NOT C=0, Output=0<br>
Row 3: A=0,B=1,C=0 &mdash; A&middot;B=0, NOT C=1, Output=1<br>
Row 4: A=0,B=1,C=1 &mdash; A&middot;B=0, NOT C=0, Output=0<br>
Row 5: A=1,B=0,C=0 &mdash; A&middot;B=0, NOT C=1, Output=1<br>
Row 6: A=1,B=0,C=1 &mdash; A&middot;B=0, NOT C=0, Output=0<br>
Row 7: A=1,B=1,C=0 &mdash; A&middot;B=1, NOT C=1, Output=1<br>
Row 8: A=1,B=1,C=1 &mdash; A&middot;B=1, NOT C=0, Output=1</p>
    <p data-narration-id="n27">Notice that adding intermediate columns makes it straightforward to avoid errors. The output is 0 only when A&middot;B=0 AND C=1 (rows 2, 4, 6).</p>
  </div></div>
</div>

<div class="key-fact" data-narration-id="n28" data-revision-tip="Cover this. Without looking: how many rows does a three-input truth table need? Write the eight combinations of A, B, C in order.">
  <div class="key-fact-label">Key Fact</div>
  <p>A truth table for n inputs has 2<sup>n</sup> rows. Two inputs: 4 rows. Three inputs: 8 rows. Always list input combinations in binary counting order (000, 001, 010, 011, 100, 101, 110, 111) to guarantee every combination is covered. Add intermediate columns for complex expressions.</p>
</div>

<h2 data-narration-id="n29">Logic Circuits and Expressions</h2>
<p data-narration-id="n30">A logic circuit diagram shows gates connected by wires. Your exam may ask you to convert between a Boolean expression and a circuit diagram, or to complete a truth table for a given circuit. Work methodically: label the output of each gate as an intermediate value, then trace each row of the truth table through the circuit gate by gate.</p>
<p data-narration-id="n31">Conversely, given a circuit diagram, write the expression by reading the gates from inputs to output. The output of each gate becomes the input expression for the next. Brackets group gates that feed into a later gate. This skill requires practise &mdash; draw example circuits and write their expressions until the pattern becomes automatic.</p>

--- CONCLUSION_HTML ---
<h3 data-narration-id="n33">Key Takeaways</h3>
<ul>
  <li data-narration-id="n34">Four gates to know: NOT (inverts input), AND (output 1 when all inputs are 1), OR (output 1 when any input is 1), XOR (output 1 when exactly one input is 1 &mdash; not both). XOR&rsquo;s A=1, B=1 &rarr; 0 is the critical distinction from OR.</li>
  <li data-narration-id="n35">Boolean notation: A &middot; B = AND, A + B = OR, A &oplus; B = XOR, overbar = NOT. Always evaluate brackets first. A three-input truth table needs 8 rows (2<sup>3</sup>).</li>
  <li data-narration-id="n36">Add intermediate columns when completing truth tables for combined expressions, and work through each row systematically to avoid errors.</li>
</ul>

--- EXAM_TIP_HTML ---
<p data-narration-id="n32">Boolean logic questions typically appear as 2&ndash;6 marks. For truth tables, always add intermediate columns for sub-expressions in brackets before filling in the final output column &mdash; this prevents cascading errors. XOR is the gate students most often confuse with OR: remember, XOR outputs 0 when both inputs are 1. For three-input tables, write all 8 input rows in binary counting order first (000 to 111) before filling any outputs. For expression-to-circuit questions, draw each gate in the order you would evaluate the expression (innermost brackets first). The Boolean notation &middot; for AND, + for OR, &oplus; for XOR, and overbar for NOT will appear in questions &mdash; make sure you recognise each symbol instantly.</p>
