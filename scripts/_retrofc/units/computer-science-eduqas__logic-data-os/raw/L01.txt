--- CONTENT_HTML ---
<h2 data-narration-id="n1">What Are Logical Operators?</h2>
<p data-narration-id="n2">Computers make decisions by evaluating conditions that are either true or false. <dfn class="term" data-def="Operators that work on Boolean (true/false) values and return a Boolean result.">Logical operators</dfn> are the building blocks of this decision-making. They combine Boolean values &mdash; values that are either 1 (true) or 0 (false) &mdash; and produce a Boolean result. In hardware, these operators are implemented as <dfn class="term" data-def="An electronic component that takes one or more binary inputs and produces a single binary output based on a logical rule.">logic gates</dfn>. In software, they appear inside <code>if</code> statements and while loops. Understanding them is essential for both circuit design and programming.</p>

<p data-narration-id="n3">A <dfn class="term" data-def="A table showing all possible input combinations for a logical expression and the output produced by each combination.">truth table</dfn> is the standard way to describe a logical operator&rsquo;s behaviour. Each row represents one combination of inputs. For two inputs A and B there are four possible combinations: (0,0), (0,1), (1,0) and (1,1). You must always show every row &mdash; leaving rows out drops marks in the exam.</p>

<div class="key-fact" data-narration-id="n4" data-revision-tip="Cover this and write the output column from memory for AND, OR, NOT and XOR truth tables.">
  <div class="key-fact-label">Key Fact</div>
  <p>There are four logical operators you need to know: AND, OR, NOT and XOR. Each has a standard symbol used in circuit diagrams and a truth table showing every possible input-output combination.</p>
</div>

<h2 data-narration-id="n5">The AND Operator</h2>
<p data-narration-id="n6">AND outputs 1 only when <strong>both</strong> inputs are 1. Think of it as a strict gatekeeper: every condition must be met. In Boolean notation, AND is written with a dot or by placing letters side by side: A&middot;B or AB.</p>

<table data-narration-id="n7">
  <thead><tr><th>A</th><th>B</th><th>A AND B</th></tr></thead>
  <tbody>
    <tr><td>0</td><td>0</td><td>0</td></tr>
    <tr><td>0</td><td>1</td><td>0</td></tr>
    <tr><td>1</td><td>0</td><td>0</td></tr>
    <tr><td>1</td><td>1</td><td>1</td></tr>
  </tbody>
</table>

<h2 data-narration-id="n8">The OR Operator</h2>
<p data-narration-id="n9">OR outputs 1 when <strong>at least one</strong> input is 1. It only outputs 0 when both inputs are 0. In Boolean notation, OR is written with a plus sign: A + B.</p>

<table data-narration-id="n10">
  <thead><tr><th>A</th><th>B</th><th>A OR B</th></tr></thead>
  <tbody>
    <tr><td>0</td><td>0</td><td>0</td></tr>
    <tr><td>0</td><td>1</td><td>1</td></tr>
    <tr><td>1</td><td>0</td><td>1</td></tr>
    <tr><td>1</td><td>1</td><td>1</td></tr>
  </tbody>
</table>

<h2 data-narration-id="n11">The NOT Operator</h2>
<p data-narration-id="n12">NOT is a single-input operator that <strong>inverts</strong> its input: 0 becomes 1 and 1 becomes 0. It is also called a complement or inverter. In Boolean notation, NOT is written as an overbar &mdash; for example, NOT A is written as &#256; (A with an overbar) &mdash; or sometimes as A&prime; or !A.</p>

<table data-narration-id="n13">
  <thead><tr><th>A</th><th>NOT A</th></tr></thead>
  <tbody>
    <tr><td>0</td><td>1</td></tr>
    <tr><td>1</td><td>0</td></tr>
  </tbody>
</table>

<h2 data-narration-id="n14">The XOR Operator</h2>
<p data-narration-id="n15">XOR (exclusive OR) outputs 1 when the inputs are <strong>different</strong>. If both inputs are the same &mdash; both 0 or both 1 &mdash; the output is 0. XOR is denoted A &oplus; B. It is particularly useful in binary addition circuits (half adders) and encryption.</p>

<table data-narration-id="n16">
  <thead><tr><th>A</th><th>B</th><th>A XOR B</th></tr></thead>
  <tbody>
    <tr><td>0</td><td>0</td><td>0</td></tr>
    <tr><td>0</td><td>1</td><td>1</td></tr>
    <tr><td>1</td><td>0</td><td>1</td></tr>
    <tr><td>1</td><td>1</td><td>0</td></tr>
  </tbody>
</table>

<div class="key-fact" data-narration-id="n17" data-revision-tip="Test yourself: write XOR's output column from memory, then check. Remember: outputs 1 when inputs are different.">
  <div class="key-fact-label">Key Fact</div>
  <p>XOR outputs 1 only when its two inputs <em>differ</em>. This distinguishes it from OR: OR outputs 1 when both inputs are 1, but XOR outputs 0 in that case because the inputs are the same.</p>
</div>

    <svg class="collapsible-icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><polyline points="6 9 12 15 18 9"/></svg>

  <div class="collapsible-content"><div class="collapsible-inner">
    <p data-narration-id="n21">The most common error in truth table questions is confusing XOR with OR. Remember: OR outputs 1 for the row (1,1), but XOR outputs 0 for that row because the inputs are the same. Write the row (1,1) carefully for every XOR column.</p>
    <p data-narration-id="n22">A second mistake is filling in only the output column for combined-gate questions. The mark scheme awards one mark per correct cell, including intermediate columns. If the question shows a two-stage gate circuit, add an intermediate column for each gate stage and fill every row before moving to the final output.</p>
    <p data-narration-id="n23">A third mistake is mixing up Boolean notation with arithmetic. In Boolean expressions, A&middot;B means AND and A + B means OR. The + symbol does NOT mean addition here. Students who confuse arithmetic addition with Boolean OR often get three-variable expressions wrong.</p>
  </div></div>

<h2 data-narration-id="n24">NAND and NOR Gates</h2>
<p data-narration-id="n25">Two additional gates appear in this course: NAND and NOR. A <dfn class="term" data-def="A logic gate equivalent to an AND gate followed by a NOT gate; outputs 0 only when all inputs are 1.">NAND gate</dfn> is AND followed by NOT &mdash; its output is the inverse of AND. A <dfn class="term" data-def="A logic gate equivalent to an OR gate followed by a NOT gate; outputs 1 only when all inputs are 0.">NOR gate</dfn> is OR followed by NOT &mdash; its output is the inverse of OR. NAND and NOR are called universal gates because any logic circuit can be built from NAND gates alone (or NOR gates alone).</p>

<table data-narration-id="n26">
  <thead><tr><th>A</th><th>B</th><th>NAND</th><th>NOR</th></tr></thead>
  <tbody>
    <tr><td>0</td><td>0</td><td>1</td><td>1</td></tr>
    <tr><td>0</td><td>1</td><td>1</td><td>0</td></tr>
    <tr><td>1</td><td>0</td><td>1</td><td>0</td></tr>
    <tr><td>1</td><td>1</td><td>0</td><td>0</td></tr>
  </tbody>
</table>

<p data-narration-id="n27">Notice that NAND outputs 0 only in the last row (both inputs 1), while NOR outputs 1 only in the first row (both inputs 0). These are exactly opposite to AND and OR respectively. The practical importance of <dfn class="term" data-def="Gates that are functionally complete: any logic circuit, however complex, can be constructed entirely from copies of a single gate of this type.">universal gates</dfn> is that hardware manufacturers can produce one type of gate in bulk and use it to build every other gate, simplifying chip design and reducing manufacturing costs.</p>

--- CONCLUSION_HTML ---
<h3 data-narration-id="n29">Key Takeaways</h3>
<ul>
  <li data-narration-id="n30">AND outputs 1 only when both inputs are 1; OR outputs 1 when at least one input is 1; NOT inverts its single input; XOR outputs 1 when inputs differ.</li>
  <li data-narration-id="n31">For combined-gate truth tables, add an intermediate column for each gate stage and fill every cell &mdash; each cell earns an independent mark.</li>
  <li data-narration-id="n32">NAND and NOR are the inverse of AND and OR respectively, and are called universal gates because any circuit can be built from either one alone.</li>
</ul>

--- EXAM_TIP_HTML ---
<p data-narration-id="n28">Truth table questions award one mark per correct output cell &mdash; not one mark for the whole table. Always write every row, include intermediate columns for combined circuits, and never leave a cell blank. For a two-input truth table, you need exactly four rows. For XOR specifically, double-check the (1,1) row: the output is 0, not 1, because the inputs are the same. In describe or explain questions about logic gates, name the operator (AND/OR/NOT/XOR/NAND/NOR) and state the condition that produces a 1 output.</p>
