<h2 data-narration-id="n1">Why Sort Data?</h2>
<p data-narration-id="n2">Sorting data into order is a fundamental computing task. Binary search requires sorted data. Databases display results in a meaningful order. A music app shows albums alphabetically. A leaderboard ranks scores from highest to lowest. The specification requires you to know two <dfn class="term" data-def="An algorithm that arranges data into a specified order, such as ascending numerical order or alphabetical order.">sorting algorithms</dfn>: bubble sort and merge sort. You must understand how each works and be able to compare them.</p>

<h2 data-narration-id="n3">Bubble Sort</h2>
<p data-narration-id="n4"><dfn class="term" data-def="A sorting algorithm that makes repeated passes through a list, comparing adjacent pairs of items and swapping them if they are in the wrong order. Each pass moves the largest unsorted item to its correct position at the end of the unsorted portion.">Bubble sort</dfn> works by repeatedly comparing adjacent pairs of items and swapping them if they are in the wrong order. After the first pass, the largest item has &ldquo;bubbled&rdquo; to the last position. After the second pass, the second largest is in place. The algorithm continues until a complete pass produces no swaps &mdash; which means the list is sorted.</p>
<p data-narration-id="n5"><strong>The mechanics, step by step:</strong> Compare items at positions 1 and 2 &mdash; swap if needed. Compare positions 2 and 3 &mdash; swap if needed. Continue to the end of the list. That completes one pass. Repeat passes until no swaps occur.</p>

<div class="key-fact" data-narration-id="n6" data-revision-tip="Cover this and recall: two advantages and two disadvantages of bubble sort.">
  <div class="key-fact-label">Key Fact</div>
  <p><strong>Advantages of bubble sort:</strong> Simple to understand and implement. Sorts in place (no extra memory needed). Can detect an already-sorted list early (zero swaps on the first pass). <strong>Disadvantages:</strong> Very slow for large datasets &mdash; many passes and many comparisons are needed. Inefficient even in the average case.</p>
</div>

<h2 data-narration-id="n12">Merge Sort</h2>
<p data-narration-id="n13"><dfn class="term" data-def="A sorting algorithm that uses a divide-and-conquer approach: repeatedly splitting a list in half until each sub-list contains one item, then merging the sub-lists back together in sorted order.">Merge sort</dfn> uses a <strong>divide-and-conquer</strong> approach. It repeatedly splits the list in half until each sub-list contains a single item. A list of one item is inherently sorted. It then merges pairs of sub-lists back together, placing items in the correct order during each merge. The merge phase is where the actual sorting happens.</p>

<div class="key-fact" data-narration-id="n19" data-revision-tip="Test yourself: Explain the key advantage of merge sort over bubble sort, and the one disadvantage it has.">
  <div class="key-fact-label">Key Fact</div>
  <p><strong>Advantages of merge sort:</strong> Much faster than bubble sort for large datasets. Consistent performance regardless of how the data is initially ordered. <strong>Disadvantages:</strong> Requires extra memory to store the temporary sub-lists during the merging process. More complex to implement than bubble sort.</p>
</div>

<h2 data-narration-id="n20">Comparing Bubble Sort and Merge Sort</h2>
<p data-narration-id="n21">The two algorithms make a direct trade-off between simplicity and speed. Bubble sort is easy to code and uses no extra memory, but it becomes impractical for lists with more than a few hundred items. Merge sort is consistently fast even on very large lists, but it requires extra memory for the sub-lists and is harder to implement correctly.</p>
<p data-narration-id="n22">As with searching algorithms, the right choice depends on the context. For a small list of exam results in a classroom app, bubble sort is perfectly adequate. For sorting millions of customer records in a bank&rsquo;s database overnight, merge sort (or a similar efficient algorithm) is essential.</p>

--- CONCLUSION_HTML ---
<h3 data-narration-id="n34">Key Takeaways</h3>
<ul>
  <li data-narration-id="n35">Bubble sort makes repeated passes comparing adjacent pairs, swapping as needed until no swaps occur. It is simple and in-place, but slow for large datasets.</li>
  <li data-narration-id="n36">Merge sort splits the list to individual items then merges them back in order. It is much faster for large data but uses extra memory and is more complex to write.</li>
  <li data-narration-id="n37">The choice between them depends on dataset size, available memory, and whether implementation simplicity matters more than speed.</li>
</ul>
