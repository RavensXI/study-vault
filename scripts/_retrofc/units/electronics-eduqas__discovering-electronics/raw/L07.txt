--- DESCRIPTION ---
How comparator ICs convert a continuous sensor voltage into a clean high or low digital output.

--- CONTENT_HTML ---
<h2 data-narration-id="n1">Bridging the Analogue and Digital Worlds</h2>
<p data-narration-id="n2">A sensor voltage divider produces a smoothly varying output &mdash; a continuous analogue signal that could sit at any value between 0 V and the supply. But a logic gate or microcontroller needs a clean binary signal: decisively HIGH or decisively LOW. A <dfn class="term" data-def="An integrated circuit that compares two input voltages and outputs a digital HIGH or LOW depending on which input is larger.">voltage comparator</dfn> is the bridge between these two worlds. It performs one simple operation: it compares two voltages and tells you which is bigger.</p>

<h2 data-narration-id="n3">How a Comparator Works</h2>
<p data-narration-id="n4">A comparator IC has two inputs and one output:</p>
<ul>
  <li data-narration-id="n5"><strong>Non-inverting input (+):</strong> receives the sensor signal (the varying voltage from the transducer voltage divider).</li>
  <li data-narration-id="n6"><strong><dfn class="term" data-def="The negative input of a comparator or op-amp, marked with a minus sign. In a comparator, this input typically receives the reference voltage.">Inverting input (&minus;)</dfn>:</strong> receives the reference voltage &mdash; a fixed voltage set by a potential divider or potentiometer, representing the threshold at which the output should switch.</li>
  <li data-narration-id="n7"><strong>Output:</strong> switches to HIGH (close to the positive supply) when the non-inverting input is greater than the reference; switches to LOW (close to 0 V) when the non-inverting input is less than the reference.</li>
</ul>
<p data-narration-id="n8">The rule is easy to remember: <strong>+&nbsp;>&nbsp;&minus; &rArr; output HIGH; +&nbsp;&lt;&nbsp;&minus; &rArr; output LOW</strong>. The output does not sit at an in-between voltage &mdash; because the comparator has an extremely high <dfn class="term" data-def="The gain of an op-amp or comparator with no feedback, typically 100,000 or more. Even the tiniest difference between the inputs is amplified to drive the output to its supply rail.">open-loop gain</dfn>, the tiniest difference between the inputs is amplified to drive the output rail-to-rail.</p>

<div class="key-fact" data-narration-id="n9" data-revision-tip="Cover this and write the two comparator output rules: what happens to the output when (+) &gt; (−), and what happens when (+) &lt; (−)?">
  <div class="key-fact-label">Key Fact</div>
  <p>Comparator output rule: if V(+) &gt; V(&minus;) then output = HIGH. If V(+) &lt; V(&minus;) then output = LOW. The output switches sharply because the open-loop gain is very large &mdash; it never sits midway.</p>
</div>

<h2 data-narration-id="n10">The Inverting Input Gets the Reference &mdash; and Why</h2>
<p data-narration-id="n11">The convention for this specification is: the <strong>inverting (&minus;) input gets the reference voltage</strong> and the <strong>non-inverting (+) input gets the sensor signal</strong>. This means:</p>
<ul>
  <li data-narration-id="n12">When the sensor signal exceeds the reference, the output goes HIGH. If the sensor is an LDR divider whose output rises in bright light, the output goes HIGH in bright light &mdash; which is what a light-activated relay circuit needs.</li>
  <li data-narration-id="n13">When the sensor signal drops below the reference, the output goes LOW. This LOW state can be used to signal an alarm condition or turn off a load.</li>
</ul>
<p data-narration-id="n14">Swapping the inputs produces an inverted comparator that does the opposite. Be explicit about which input receives which signal in every circuit drawing and answer.</p>

<h2 data-narration-id="n15">Setting the Reference Voltage</h2>
<p data-narration-id="n16">The reference voltage is set by a second voltage divider (often a fixed resistor and a variable resistor or potentiometer) connected between the supply and 0 V. Adjusting the potentiometer changes the threshold &mdash; the point at which the comparator switches. For example, with a 9 V supply and a potentiometer set to give 4.5 V at the inverting input, the comparator switches its output when the sensor voltage crosses 4.5 V.</p>

  <p>Convention: sensor signal &rarr; non-inverting input (+); reference voltage &rarr; inverting input (&minus;). Output HIGH when sensor exceeds reference; output LOW when sensor is below reference.</p>
</div>

<h2 data-narration-id="n22">Output Drive Limitations</h2>
<p data-narration-id="n23">A comparator IC can directly drive a small LED (with a series current-limiting resistor), a logic gate input, or another comparator input. It <em>cannot</em> directly drive a motor, solenoid or lamp because these require more current than the comparator output can supply. A transistor or MOSFET transducer driver must be inserted between the comparator output and the high-current load. This is explicitly in the specification under the comparison of comparator, transistor and MOSFET drive capabilities.</p>

--- CONCLUSION_HTML ---
<h3 data-narration-id="n29">Key Takeaways</h3>
<ul>
  <li data-narration-id="n30">A comparator compares two voltages and outputs HIGH if V(+) &gt; V(&minus;), or LOW if V(+) &lt; V(&minus;). The output switches sharply because the open-loop gain is very large.</li>
  <li data-narration-id="n31">Convention: sensor signal connects to the non-inverting (+) input; reference voltage connects to the inverting (&minus;) input. Swapping these inputs inverts the output behaviour.</li>
  <li data-narration-id="n32">A comparator IC has limited output drive capability. High-current loads (motors, lamps, relays) need a transistor or MOSFET transducer driver between the comparator output and the load.</li>
</ul>

--- EXAM_TIP_HTML ---
<p data-narration-id="n28">For comparator questions, the most common mistake is failing to determine the output state when given specific input voltages. Always write &ldquo;V(+) = [value]&rdquo; and &ldquo;V(&minus;) = [reference]&rdquo; explicitly, then apply the rule: if + &gt; &minus;, output HIGH. If &minus; &gt; +, output LOW. Examiners explicitly note that students cannot apply this rule when input values are given &mdash; it costs two marks. Also remember: a comparator cannot drive a motor or lamp directly. If an output device needs more than a few milliamps, state that a transistor or MOSFET driver is required between the comparator output and the load.</p>
