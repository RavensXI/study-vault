--- DESCRIPTION ---
How RAM, ROM and virtual memory work together to keep a computer running.

--- CONTENT_HTML ---
<p data-narration-id="n1">Every time you open an app, load a game or start typing an essay, the processor needs somewhere to keep the instructions and data it is working on at that exact moment. That job belongs to <dfn class="term" data-def="Memory that the CPU can access directly and very quickly, holding the data and instructions currently in use.">primary storage</dfn>, which is usually just called memory. It sits between the CPU and the much slower secondary storage, such as a hard drive or solid state drive.</p><p data-narration-id="n2">The CPU can only work with data that is held in primary storage, because that is the only storage it is able to read from directly. Anything saved on secondary storage has to be copied into memory first before the processor can touch it. This is the whole reason computers need memory: without it, the CPU would have nothing to fetch and execute.</p><p data-narration-id="n3">In a typical computer, primary storage is made up of two main types of memory: RAM and ROM. They sound similar and both sit close to the processor, but they do very different jobs, and exam questions love to test whether you can tell them apart.</p><h2 data-narration-id="n4">RAM &mdash; the computer&rsquo;s working memory</h2><p data-narration-id="n5">RAM stands for Random Access Memory. It holds the operating system, the applications you currently have open and the files you are actively using. When you launch a program, a copy of it is loaded from secondary storage into RAM so that the CPU can reach it quickly. The more RAM a computer has, the more programs it can keep running smoothly at the same time.</p><p data-narration-id="n6">RAM has two defining characteristics. First, it can be both read from and written to, so its contents change constantly as you use the machine. Second, it is <dfn class="term" data-def="Describes memory that loses all of its contents when the power is switched off.">volatile</dfn>, which means everything stored in it is lost the instant the power is turned off. That is why unsaved work vanishes if your computer suddenly shuts down.</p><p data-narration-id="n7">A useful way to picture this is a desk. RAM is like the top of the desk, where you spread out the books and papers you are using right now so you can reach them quickly. Secondary storage is like the filing cabinet in the corner: it holds far more, but you have to get up and fetch things from it before you can work on them. A bigger desk lets you have more open at once, just as more RAM lets you run more programs.</p><div class="key-fact" data-narration-id="n8" data-revision-tip="Cover this and write down whether RAM is volatile or non-volatile, and what that word means."><div class="key-fact-label">Key Fact</div><p>RAM is volatile and can be both read from and written to. It stores the programs, data and operating system that are in use right now, and loses everything when the power is cut.</p></div><h2 data-narration-id="n9">ROM &mdash; the start-up memory</h2><p data-narration-id="n10">ROM stands for Read Only Memory. As the name suggests, under normal use it can only be read from, not written to, so its contents stay fixed. ROM is <dfn class="term" data-def="Describes memory that keeps its contents even when the power is switched off.">non-volatile</dfn>, which means it holds on to its data even when the computer is switched off.</p><p data-narration-id="n11">The main purpose of ROM is to store the small set of start-up instructions the computer needs the instant it is switched on. This program is often called the <dfn class="term" data-def="A small program stored in ROM that runs when a computer is switched on and begins loading the operating system.">bootstrap</dfn>. It tells the computer how to check its hardware and then load the operating system from secondary storage into RAM so the machine can begin working.</p><div class="collapsible"><button class="collapsible-toggle" aria-expanded="false"><span>What happens when you switch a computer on?</span><svg class="collapsible-icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><polyline points="6 9 12 15 18 9"/></svg></button><div class="collapsible-content"><div class="collapsible-inner"><p data-narration-id="n12">When the power button is pressed, RAM is empty, so the CPU has nothing to run. It turns to ROM, which is non-volatile and still holds the bootstrap instructions. The CPU follows these instructions to test the hardware and then copy the operating system from secondary storage into RAM. Once the operating system is loaded, the computer is ready to use. Keeping these instructions in ROM guarantees they are always there, even after the machine has been unplugged for weeks.</p></div></div></div><h2 data-narration-id="n13">Telling RAM and ROM apart</h2><p data-narration-id="n14">The clearest way to compare the two is by three features: whether they are volatile, whether they can be written to, and what they store. RAM is volatile, can be read and written, and holds whatever is running now. ROM is non-volatile, is normally read only, and holds the fixed start-up instructions. RAM is also usually much larger than ROM, because it has to hold everything currently in use, whereas ROM only needs room for a small boot program.</p><div class="key-fact" data-narration-id="n15" data-revision-tip="Close this, then list the three differences between RAM and ROM from memory."><div class="key-fact-label">Key Fact</div><p>ROM is non-volatile and read only, and stores the boot-up (bootstrap) instructions. RAM is volatile and read-write, and stores the programs and data in current use.</p></div><h2 data-narration-id="n16">Virtual memory</h2><p data-narration-id="n17">RAM is fast but limited in size. If you open too many programs, or a single program is very large, RAM can fill up completely. When that happens, the computer uses a technique called <dfn class="term" data-def="An area of secondary storage used as if it were extra RAM when the real RAM becomes full.">virtual memory</dfn>. A section of the secondary storage &mdash; the hard drive or solid state drive &mdash; is set aside and treated as though it were extra RAM.</p><p data-narration-id="n18">Here is how it works. Data in RAM that is not being used at that moment is moved out of RAM and written to this reserved area of secondary storage. That frees up space in RAM for the programs the user is actively working with. When the moved data is needed again, it is copied back into RAM, and other unused data may be swapped out to make room. This constant transfer of data between RAM and secondary storage is what keeps a full system running instead of freezing.</p><div class="collapsible"><button class="collapsible-toggle" aria-expanded="false"><span>Why does relying on virtual memory slow a computer down?</span><svg class="collapsible-icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><polyline points="6 9 12 15 18 9"/></svg></button><div class="collapsible-content"><div class="collapsible-inner"><p data-narration-id="n19">Secondary storage is far slower to read and write than RAM. Every time data is swapped between RAM and virtual memory, the CPU has to wait for the slow secondary storage to catch up. If RAM is very full, the computer can end up spending more time shuffling data back and forth than doing useful work, and everything feels sluggish. Fitting more RAM is the best fix, because the computer then rarely needs to fall back on virtual memory at all.</p></div></div></div><div class="key-fact" data-narration-id="n20" data-revision-tip="Cover this and explain in one sentence what the computer does when RAM becomes full."><div class="key-fact-label">Key Fact</div><p>When RAM is full, the computer moves data that is not currently in use out to a reserved area of secondary storage called virtual memory, then swaps it back into RAM when it is needed again.</p></div><p data-narration-id="n21">So the three types of memory work as a team. ROM gets the machine started, RAM gives the processor a fast place to work, and virtual memory acts as a safety net when RAM runs out. Understanding which is volatile, which can be written to, and what each one stores is the key to answering almost any question on primary storage.</p>

--- CONCLUSION_HTML ---
<h3 data-narration-id="n23">Key Takeaways</h3><ul><li data-narration-id="n24">RAM is volatile, read-write memory that holds the operating system, programs and data in current use; ROM is non-volatile, read-only memory that holds the start-up instructions.</li><li data-narration-id="n25">The CPU can only work with data held in primary storage, so programs must be copied from secondary storage into RAM before they can run.</li><li data-narration-id="n26">When RAM is full, virtual memory uses a slower area of secondary storage as extra RAM, which keeps the system running but reduces performance.</li></ul>

--- EXAM_TIP_HTML ---
<p data-narration-id="n22">A very common mistake is to describe ROM simply as memory that can never be changed. Instead, say that it is read only under normal use and that it stores the start-up (bootstrap) instructions. When a question asks you to explain the difference between RAM and ROM, do not just list features &mdash; make clear comparison points about volatility, whether each can be written to, and what each one stores. If a question is about a slow computer, link full RAM to the use of virtual memory and remember that adding more RAM is the strongest improvement.</p>
