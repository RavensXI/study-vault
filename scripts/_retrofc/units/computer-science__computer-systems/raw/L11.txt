--- DESCRIPTION ---
What operating systems do to manage a computer, and how utility software keeps it running.

--- CONTENT_HTML ---
<p data-narration-id="n1">Behind every app you open and every file you save sits a layer of software you rarely see, called system software. Its job is to control the computer itself and make it usable, so that the programs you actually care about &mdash; games, browsers, word processors &mdash; have a stable place to run.</p><p data-narration-id="n2">The most important piece of system software is the <dfn class="term" data-def="System software that manages a computer&rsquo;s hardware and software and provides a platform for applications to run.">operating system</dfn>, often shortened to OS. Windows, macOS, Linux, Android and iOS are all operating systems. The OS acts as a bridge between the hardware, the applications and the person using the machine, hiding the complicated details so that everything just works.</p><h2 data-narration-id="n3">The five main jobs of an operating system</h2><p data-narration-id="n4">The first job is to provide a <dfn class="term" data-def="The part of the operating system that lets a user interact with the computer, such as a graphical desktop.">user interface</dfn>. On most home computers this is a graphical interface, with windows, icons, menus and a pointer you control with a mouse or touchpad. It gives the user a simple, visual way to run programs and manage files without typing commands. Some systems also offer a command line, where instructions are typed in as text.</p><p data-narration-id="n5">The second job is memory management and multitasking. The OS decides how the computer&rsquo;s memory is shared out, allocating an area of memory to each program that is running and moving data into and out of memory as it is needed. This careful sharing is what allows <dfn class="term" data-def="Running several programs at what appears to be the same time by rapidly switching the processor between them.">multitasking</dfn>, so you can listen to music while writing an essay and keep a browser open at the same time.</p><p data-narration-id="n6">The third job is peripheral management. Data has to be transferred between the processor and the many devices attached to a computer, such as printers, keyboards and storage drives, and this flow has to be managed so nothing is lost or muddled. The OS does this using a <dfn class="term" data-def="A small program that lets the operating system communicate with and control a particular piece of hardware.">device driver</dfn> for each piece of hardware, a small program that translates the OS&rsquo;s instructions into signals the device understands.</p><p data-narration-id="n7">The fourth job is user management. The OS lets a computer have several separate accounts, each with its own settings and files. It controls access rights, deciding what each user is allowed to see and change, which keeps one person&rsquo;s work private and stops ordinary users from altering important system settings.</p><p data-narration-id="n8">The fifth job is file management. The OS organises how data is stored, letting you name files, group them into folders, move and copy them, and save or delete them. It keeps track of where every file is physically stored on the drive so it can be found again instantly.</p><div class="key-fact" data-narration-id="n9" data-revision-tip="Cover this and list the five main jobs an operating system carries out."><div class="key-fact-label">Key Fact</div><p>An operating system carries out five key jobs: providing a user interface, managing memory and multitasking, managing peripherals through drivers, managing users and their access rights, and managing files.</p></div><div class="collapsible"><button class="collapsible-toggle" aria-expanded="false"><span>How does an operating system run several programs at once?</span><svg class="collapsible-icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><polyline points="6 9 12 15 18 9"/></svg></button><div class="collapsible-content"><div class="collapsible-inner"><p data-narration-id="n10">A single processor can really only do one thing at a time, so multitasking is a clever illusion. The operating system gives each running program a tiny slice of processor time in turn, switching between them so quickly that they all appear to run together. To make this work it must allocate each program its own area of memory and transfer data between memory and the processor as each program takes its turn. If a program is not being used at that instant, its data can be moved aside to free memory for the others.</p></div></div></div><h2 data-narration-id="n11">Utility software</h2><p data-narration-id="n12">Alongside the operating system, computers usually come with <dfn class="term" data-def="Software that carries out housekeeping and maintenance tasks to keep a computer running smoothly.">utility software</dfn>. These are small tools that carry out housekeeping tasks &mdash; the background jobs that keep a system healthy and secure but that the operating system does not always handle on its own. Three important examples are encryption software, defragmentation and data compression.</p><p data-narration-id="n13">Encryption software protects data using <dfn class="term" data-def="Scrambling data using a key so that it cannot be understood by anyone who intercepts it without the key.">encryption</dfn>. It scrambles the contents of a file into an unreadable form using a key, so that if the file is stolen or intercepted, a thief cannot make sense of it. Only someone with the correct key can turn the data back into its original form. This is vital for confidential information such as passwords, bank details and personal records.</p><p data-narration-id="n14">Defragmentation tackles a problem that builds up on hard disk drives over time. As files are saved, deleted and resaved, a single file can end up split into pieces scattered across the drive. <dfn class="term" data-def="Reorganising the files on a storage drive so the parts of each file are stored together, speeding up access.">Defragmentation</dfn> software reorganises the drive so the pieces of each file are stored next to each other again. This means the read/write head has less distance to travel, so files load faster.</p><p data-narration-id="n15">Data compression software reduces the size of files by encoding them so they use fewer bits. Smaller files take up less storage space and can be sent across a network more quickly, which is why compression is used for photos, music and email attachments. It performs a task the operating system does not do by default, which is exactly why it counts as utility software.</p><div class="key-fact" data-narration-id="n16" data-revision-tip="Close this and name the three utility programs and what each one is for."><div class="key-fact-label">Key Fact</div><p>Utility software performs housekeeping tasks the operating system may not. Encryption software scrambles data to keep it secure, defragmentation reorganises scattered files to speed up a drive, and compression shrinks files to save space and transfer time.</p></div><div class="collapsible"><button class="collapsible-toggle" aria-expanded="false"><span>Why does a fragmented hard drive slow a computer down?</span><svg class="collapsible-icon" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><polyline points="6 9 12 15 18 9"/></svg></button><div class="collapsible-content"><div class="collapsible-inner"><p data-narration-id="n17">On a hard disk drive, data is read by a moving head that travels across spinning platters. When a file is fragmented, its pieces are scattered in different places, so the head has to jump around to collect them all, and each jump takes time. The more fragmented the drive, the more the head has to move, and the slower files load. Defragmentation gathers each file&rsquo;s pieces back together so the head can read them in one smooth sweep. Solid state drives have no moving parts, so they do not benefit from defragmentation in the same way.</p></div></div></div><p data-narration-id="n18">It helps to keep system software and application software separate in your mind. Application software is the programs you use to get a job done, like a spreadsheet or a photo editor. System software &mdash; the operating system and utility programs &mdash; works quietly in the background to run the machine and keep it in good order so those applications can do their work.</p>

--- CONCLUSION_HTML ---
<h3 data-narration-id="n20">Key Takeaways</h3><ul><li data-narration-id="n21">The operating system is system software that manages the computer and provides a user interface, memory management and multitasking, peripheral management with drivers, user management, and file management.</li><li data-narration-id="n22">Utility software carries out housekeeping tasks the operating system may not, including encryption to secure data, defragmentation to reorganise scattered files, and compression to shrink file sizes.</li><li data-narration-id="n23">System software runs and maintains the machine in the background, while application software is what the user runs to complete a task.</li></ul>

--- EXAM_TIP_HTML ---
<p data-narration-id="n19">Questions often ask you to describe a function of the operating system, so learn the five jobs as distinct points rather than blurring them together. When asked to explain how the OS enables multitasking, make the link between allocating memory to each program and switching the processor between them &mdash; do not just say &lsquo;it runs many programs&rsquo;. For utility software, be ready to say why each tool is needed and to name a housekeeping task the operating system does not carry out itself. A frequent slip is to describe defragmentation as deleting files; it reorganises them, it does not remove them.</p>
