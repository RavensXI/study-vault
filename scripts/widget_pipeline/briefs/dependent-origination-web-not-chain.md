# Widget brief: Dependent origination as interconnected web

Cluster id: `dependent-origination-web-not-chain`  |  serves 5 lessons

## The one thing the widget must make concrete

Dependent origination is a simultaneous, interconnected web of conditions arising together, not a simple linear chain of causes.

## The lessons it will sit in
