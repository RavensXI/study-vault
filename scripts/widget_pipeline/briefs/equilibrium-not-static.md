# Widget brief: Dynamic equilibrium: both reactions continue

Cluster id: `equilibrium-not-static`  |  serves 5 lessons

## The one thing the widget must make concrete

At equilibrium, forward and reverse reactions both continue at equal rates simultaneously — the reaction hasn't stopped and concentrations need not be equal

> Reversible Reactions Some chemical reactions are reversible — the products can react to re-form the original reactants. A reversible reaction is shown with a double arrow (\(\rightleftharpoons\)): $$A + B \rightleftharpoons C + D$$ A simple example is the thermal decomposition of ammonium chloride: $$NH_4Cl \rightleftharpoons NH_3 + HCl$$ When heated, ammonium chloride decomposes into ammonia and hydrogen chloride. When cooled, these gases recombine to form ammonium chloride again.
