# Widget brief: Heterozygous carriers don't show recessive symptoms

Cluster id: `heterozygous-carrier-no-symptoms`  |  serves 4 lessons

## The one thing the widget must make concrete

A single dominant allele is enough to prevent a recessive disorder showing, so a carrier (Ff) is unaffected despite carrying the recessive allele.
