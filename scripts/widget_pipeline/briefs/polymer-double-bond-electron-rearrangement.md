# Widget brief: Breaking a double bond forms new single bonds using the same electrons

Cluster id: `polymer-double-bond-electron-rearrangement`  |  serves 5 lessons

## The one thing the widget must make concrete

When a C=C double bond opens during polymerisation, its electrons are used to form new single bonds with neighbouring carbons, not lost or 'broken off'.
