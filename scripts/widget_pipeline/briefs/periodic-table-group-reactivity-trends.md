# Widget brief: Group 1 vs Group 7 reactivity trends

Cluster id: `periodic-table-group-reactivity-trends`  |  serves 4 lessons

## The one thing the widget must make concrete

Reactivity increases down Group 1 (easier to lose an electron) but decreases down Group 7 (harder to gain an electron) — the trends are opposite, not the same rule.
