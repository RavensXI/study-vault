# Eduqas Food Preparation and Nutrition — Related Media Curation Prompt

You are curating `related_media` for a small batch of GCSE Food Preparation and Nutrition lessons (built from the Eduqas C560QS spec, Component 1 only). Quality bar is high: students should be able to **click any link and immediately reach the content** (a YouTube watch page that plays, a Spotify / Apple Podcasts episode page that plays, a study tool that loads, an article that opens). The single exception is Movies / TV / Documentaries — those use JustWatch UK aggregator pages because most films / shows aren't free-to-watch directly.

## Files to read

1. `docs/RELATED_MEDIA_PIPELINE.md` — full pipeline rules (read fully)
2. The lesson JSONs at `scripts/_content_food-preparation-and-nutrition-eduqas/lessons/{lesson_slug}.json` for the lessons you're assigned. You'll write back to each.

## Output schema

For each lesson in your batch, ADD a `related_media` field to its lesson JSON. Schema:

```json

    "items": [
      { "title": "Episode title", "description": "1-line context", "url": "https://open.spotify.com/episode/... OR https://podcasts.apple.com/.../id123?i=456 OR https://youtu.be/..." }
    ]
  },
  {
    "category": "Videos & Channels",
    "emoji": "📺",
    "items": [ { "title": "...", "description": "...", "url": "https://www.youtube.com/watch?v=VIDEO_ID" } ]
  },
  {
    "category": "TV Shows",
    "emoji": "🍳",
    "items": [ { "title": "Title (Year)", "description": "...", "url": "https://www.justwatch.com/uk/tv-show/SLUG" } ]
  },
  {
    "category": "Articles & Reading",
    "emoji": "📰",
    "items": [ { "title": "...", "description": "...", "url": "https://..." } ]
  },
  {
    "category": "Study Tools",
    "emoji": "🛠️",
    "items": [ { "title": "...", "description": "...", "url": "https://..." } ]
  }
]
```

**IMPORTANT — exact category names** (the `_verify_subject_build.py` validator hard-checks for these strings, so don't paraphrase):
- `Podcasts`
- `Videos & Channels`
- One of: `Movies` / `TV Shows` / `Documentaries` (pick exactly one — `TV Shows` is usually best for Food Prep because cooking TV is rich; `Documentaries` works well for sustainability / food provenance / food poverty lessons)
- `Study Tools`

`Articles & Reading` is optional but strongly recommended for Food Prep — there's lots of free public health writing (NHS Eatwell, FSA guidance, BNF explainers) that suits this subject and pushes the per-lesson item count above 6 comfortably.

If you cannot find an episode-level Podcast for a niche topic, leave a single placeholder: `{ "title": "Lesson Podcast", "description": "Generated by NotebookLM — added later by Tom", "url": "https://example.com/placeholder" }` — Tom replaces it during the manual NotebookLM pass. The verifier still passes because the **Podcasts** category is present.

## Hard rules

- **Each lesson: ≥6 items total**, spanning the four required categories (≥1 each: Podcasts, Videos & Channels, one of Movies / TV Shows / Documentaries, Study Tools). A 5th category (Articles & Reading) is welcome.
- **Every URL must be clickable** and take the student straight to the content — not a search results page, not a homepage.
- **YouTube URLs** must be `https://www.youtube.com/watch?v=VIDEO_ID` or `https://youtu.be/VIDEO_ID`. **Verify each** with the oembed endpoint before adding:
  ```
  curl -s "https://www.youtube.com/oembed?url=https%3A//www.youtube.com/watch%3Fv%3DVIDEO_ID&format=json"
  ```
  If oembed returns an error or HTTP non-200, drop it. **DO NOT use HEAD requests** — YouTube returns 200 even for deleted videos.
- **Podcasts**: link to a specific EPISODE on Spotify, Apple Podcasts, Google Podcasts, or YouTube. Not the show's homepage.
  - Good Food-Prep-relevant podcast sources: **BBC Radio 4 *The Food Programme*** (long-running, deep on provenance, sustainability, food culture, processing); BBC R4 *Inside Health* (nutrition / public-health episodes); BBC R4 *Sliced Bread* (food product claims tested — perfect for fortification / modified foods episodes); BBC World Service *The Food Chain* (global food security, food poverty, supply-chain episodes); *Hungry* (BBC Sounds); *The Sporkful* (food culture); *Off Menu* (James Acaster — entertainment but with Eduqas-style cuisine angles); *Doctor's Kitchen Podcast* (nutrition + medical conditions, presented by a UK GP); *British Nutrition Foundation* podcast where it exists; *FSA Food Stories* (FSA's own podcast).
- **Movies / TV / Documentaries**: use JustWatch UK URLs (`https://www.justwatch.com/uk/movie/{slug}` or `https://www.justwatch.com/uk/tv-show/{slug}`).
  - Strong Food-Prep titles by topic:
    - **Cooking science / functional properties:** *MasterChef UK* (BBC), *Bake Off* (Channel 4 — soggy bottom = water + gluten + heat-transfer pedagogy gold), *Heston's Feasts* (Channel 4), *Salt Fat Acid Heat* (Netflix — Samin Nosrat, four pillars of cooking science), *The Final Table* (Netflix), *Chef's Table* (Netflix).
    - **Provenance / sustainability / food poverty:** *Cowspiracy* (Netflix), *Seaspiracy* (Netflix), *Rotten* (Netflix series — episode-by-episode food-supply scandals), *Our Planet* (BBC, Attenborough — food security backdrop), *Just Eat It: A Food Waste Story* (food waste documentary), *Dirty Money: Drug Short* and *The Wagon Wheel* (Rotten S2 episode on food fraud), *Food Inc.* (US but globally relevant), *The Game Changers* (Netflix — vegetarianism / vegan diets evidence weighed).
    - **Diet and good health:** *What the Health* (Netflix — vegan-leaning, useful for evaluating evidence), *Fed Up* (sugar in the food supply), *Forks Over Knives* (plant-based diets).
    - **Cuisine / culinary tradition:** *Padma Lakshmi: Taste the Nation*, *Anthony Bourdain: Parts Unknown*, *Stanley Tucci: Searching for Italy*, *Street Food* (Netflix — by region), *Ugly Delicious* (Netflix).
- **Study Tools**: BBC Bitesize GCSE Food Preparation and Nutrition pages (these exist for Eduqas and AQA — pick the one most aligned with the lesson topic), **NHS Eatwell Guide** explainer pages, **British Nutrition Foundation** Food a Fact of Life resources (Foundation runs the UK schools' food curriculum hub — gold-standard for this subject), **FSA (Food Standards Agency)** explainer pages on food hygiene / labelling / allergens, **Public Health England / OHID** SACN reports, **WRAP UK** food waste resources, **Vegetarian Society / Vegan Society** explainer pages, **Coeliac UK** information pages, **Diabetes UK** food and diet pages, **NHS Choices** healthy eating advice, **Mintel / Kantar** consumer trends summaries (where free).
- **Articles & Reading**: NHS articles, FSA news, BNF articles, BBC Good Food explainers (free), BBC Food Science explainers, *The Guardian* food-policy pieces (where free), *Health Foundation* food-poverty analysis, *Trussell Trust* food-bank reports, *Soil Association* organic / sustainable farming explainers, *Food Foundation* Broken Plate report.
- **Free YouTube channels for Food Prep**:
  - **Two Teachers — GCSE Food Preparation and Nutrition** revision summaries (UK GCSE-pitched).
  - **Mr Gross's Food Prep videos** (search YouTube; UK GCSE Food Prep teacher channel).
  - **Sortedfood** — UK YouTube channel, strong on dish demonstrations, technique, and the "battle" series for sensory evaluation lessons.
  - **Jamie Oliver** — official channel; long-running food education content; strong on commodity-group recipes, healthy eating, school food.
  - **Bosh!** — UK plant-based channel (vegan / vegetarian recipes for lifestyle-needs lessons).
  - **Joshua Weissman** — high-quality cooking science breakdowns (US but topical).
  - **Adam Ragusea** — YouTube food-science explainer (US, but excellent on Maillard, gelatinisation, emulsification, fermentation).
  - **Ethan Chlebowski** — cooking-science depth (YouTube, US).
  - **Pro Home Cooks** — fermentation / preservation focus.
  - **Food Standards Agency** YouTube — short videos on food hygiene, allergens, food poisoning bacteria.
  - **NHS** YouTube — short healthy-eating, Eatwell Guide, malnutrition, baby weaning videos.
  - **British Nutrition Foundation** YouTube — short videos on nutrient functions, dietary advice.
  - **Doctor Mike** — for diet / health condition lessons (CVD, diabetes, anaemia).
  - **TED talks on food** (Mark Bittman, Jamie Oliver "Teach Every Child About Food", Dan Barber on food systems, Mary Roach on the science of digestion).
- **No Wikipedia in primary slots** — fine as a Study Tool occasionally but ≤1 of 6.
- **No Save My Exams / PMT / MME / Revision World / Study Mind / Primrose Kitten** — banned per pipeline doctrine.
- **No reproduction of past papers, mark schemes, or exam-board "model answers"** — that's the copyright moat we're protecting.
- **Tonal match**: items must connect to the LESSON's topic, not just the subject. A Salt Fat Acid Heat episode on "Heat" goes on the Heat Transfer lesson, not the Sustainability lesson. A FSA food-poisoning explainer goes on the Food Poisoning lesson, not the Recipe Development lesson.
- **UK-relevance preferred**: students are British. Pick UK examples and outlets (NHS, FSA, BNF, BBC Good Food, Coeliac UK, Diabetes UK, BBC Food Programme) first; international fine if best fit.
- **Sensitive content**: Food Prep covers eating disorders, food poverty, obesity, food poisoning outbreaks. Pick study-appropriate sources. Avoid sensationalist tabloid coverage of food scandals; prefer analytical pieces (BBC, Guardian, Health Service Journal, Health Foundation, Food Foundation) over front-page tabloids.

## Verification step (mandatory)

For each YouTube URL, run the oembed check before including. Drop and replace if it fails. For other URLs, sanity-check by reading the URL — does it look like a direct content page? If `?search=` or homepage-like (e.g. `https://www.bbc.co.uk/bitesize`) — replace with a deeper link.

## How to write back

For each lesson:
1. Read `scripts/_content_food-preparation-and-nutrition-eduqas/lessons/{lesson_slug}.json`
2. Add the `related_media` field to the JSON object (preserve all other fields)
3. **Preserve any existing `related_media`** — if there's already a "Podcasts" category with a "Lesson Podcast" item (from the StudyVault podcast generator or the placeholder above), don't overwrite. Add curated podcasts alongside it under the same category, with the StudyVault podcast first.
4. Write back to the same path.

## Output

Return only:
```
RELATED_MEDIA_DONE: lessons={N}, files=<comma list>
```

Don't echo curated content back. Just write to disk and confirm.
