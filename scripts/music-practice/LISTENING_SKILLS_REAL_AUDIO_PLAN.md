# Rebuild listening-skills on real recordings — plan (agreed 11 Aug 2026)

## Why

The listening-skills drills use **constructed** excerpts generated by
`gen_excerpts.py`. Tom's verdict on reviewing candidates: *"all of the generated
ones are too clean, would be too easy for someone who knew the answer, but I
can't verify because I'm not musically inclined."*

Two separate problems, both real:

1. **Too clean.** Synthetic clips are unambiguous in a way real music is not, so
   they train recognition of the synthesiser rather than of the musical feature.
2. **Unverifiable by the owner.** Tom cannot adjudicate "does this sound minor?",
   so any synthetic clip's answer key rests on the generator alone.

There is also a trap: **do not mix one real clip into a synthetic tier.** The
real one stands out as the odd item for reasons that have nothing to do with
music. Conversion is all-or-nothing per tier.

## The unlock

Use real recordings **of named works**. The answer then stops being an ear
judgement and becomes a documented fact: nobody has to trust their ear that a
clip sounds minor, because Mozart's Symphony No. 40 *is* in G minor and any
score or reference confirms it. Tom's check becomes "is this really the opening
of the Chopin Nocturne?" — answerable without musical training.

This is already how the AoS1 drills work.

## Scope

- **L1 Hearing Tonality** → convert fully to real excerpts.
- **L3 Texture, Devices and Cadences** → convert the texture questions; cadences
  are a harder case (a cadence needs a precise two-chord window) so keep the
  constructed cadence clips unless a clean real window is found.
- **L2 Hearing Instruments and Families** → already real recordings. It needs
  only ONE more gold question, so this is a small sourcing job, not a rebuild.
  Route used before: Commons / US military bands, CC0 or PD (see task #39).
- **aos-listening L1 (AoS2 popular music)** → **stays synthetic.** There is no
  public-domain rock or pop. Either keep the constructed clips, or link out to
  official recordings rather than hosting. Record the reason in the lesson so
  nobody "fixes" it later.

## Method

1. For each work, pick a window where the feature is unambiguous and nothing
   else competes — e.g. tonality windows that avoid a modulation, texture
   windows that avoid a texture change mid-clip.
2. Trim with ffmpeg to 10-20s. Keep the existing naming and provenance style.
3. Upload to R2 and add to `AUDIO_PROVENANCE.md`.
4. Rewrite the questions so the stem names no work (the student must hear it),
   but the EXPLANATION names it, so the answer is auditable afterwards.
5. Re-run `python scripts/_audit_practice_tiers.py` — every tier must be >= 4.

## Constraints carried over

- Licence: PD or CC0 or CC BY only. **CC BY-SA is excluded** — derivative risk.
- One work must not supply both a teaching example and the answer to a question
  in the same tier, or the drill becomes memory rather than listening.
- MD5-check every new clip against the audio already in use. Regenerating from
  `gen_excerpts.py` seeds off a fixed `1000 + index`, so it reproduces existing
  clips byte-for-byte — this already caused seven duplicate "candidates" to be
  offered for review on 11 Aug.
