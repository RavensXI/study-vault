Edexcel-specific topics not on AQA (unique_to_target)
-----------------------------------------------------
1. Two's complement signed integers (2.1.2) — fresh worked example
   needed. AQA 8525 does not assess two's complement.
2. Arithmetic binary shift (2.1.4) — AQA assesses logical shifts only.
3. Binary multiples kibibyte/mebibyte/gibibyte/tebibyte (2.3.1) —
   AQA uses decimal SI prefixes (kB = 1000 bytes); Edexcel uses 1024-
   based binary multiples. Different unit system.
4. Audit trails and code reviews for robust software (3.2.3) — AQA
   has no equivalent topic.
5. Network topologies bus/star/mesh (4.1.8) — AQA 8525 dropped
   topologies; Edexcel still requires them.
6. AI, machine learning and robotics with four named ethical issues
   (5.2.2) — AQA covers only autonomous vehicles, not the full ML/
   bias/accountability/liability framing.
7. CSV file handling (6.4.2) — AQA 8525 explicitly excludes file I/O
   at GCSE; Edexcel requires reading and writing CSV.
8. Pattern check validation (6.4.3) — fourth validation type; AQA
   covers length/presence/range only.

   truth tables for up to three inputs.

   — Edexcel 2.3.2 only assesses lossy vs lossless as concepts.

   2.2.1 only assesses 7-bit ASCII.

Question types registered
-------------------------
14 question types reflecting Edexcel's Paper 1 command-word taxonomy:
  Multiple Choice / Give-State-Name / Identify (1m)
  Define / Describe / Convert / Calculate (2m)
  Calculate (3m)
  Describe / Explain / Complete a Trace Table (4m)
  Complete an Algorithm / Discuss / Write a Subprogram (6m)

Differs from AQA in command-word framing: Edexcel uses Describe (2-4m)
and Discuss (6m) and Identify (1m); AQA uses Compare and Contrast (6m),
Convert Number Base (3m), Write SQL (5m). No 8-mark Extended Response
slot — Edexcel caps written-paper questions at 6 marks.

Programming language decision
-----------------------------
Python 3 only. Matches the spec's stated language and Edexcel's
Programming Language Subset (PLS) v6. C# is theoretically allowed but
the PLS is Python-only, and Edexcel's official teaching materials use
Python. All Unit 6 lessons use Python syntax (def, for/while, lists,
dictionaries for records).

Pseudocode policy
-----------------
Edexcel's spec footnote at 1.2 explicitly states pseudocode is "an
informal written description of a program" with no strict syntax
requirement. Unit 1 lessons use plain-English step-by-step descriptions,
NOT a formal pseudocode dialect (no FOR..ENDFOR, no ← assignment).
This matters: AQA-style pseudocode in worked examples would mislead
students into thinking strict syntax is required.

Modify, Make) as the standard GCSE programming pedagogy.
