KEY ADAPTATIONS (where Edexcel diverges)
- Joint types: Edexcel requires 4 types (pivot, hinge, condyloid, ball-and-socket) vs AQA's 2 (hinge + ball-and-socket). Add pivot (atlas-axis) and condyloid (wrist) coverage.
- Muscle fibre types: Edexcel uniquely splits into Type I, IIa, IIx (AQA only fast/slow).
- Bone classification: Edexcel adds long/short/flat/irregular shape classification (AQA omitted).
- Skill classification continua: Edexcel uses basic-complex / open-closed / high-org-low-org. AQA used basic-complex / open-closed / self-paced-externally-paced. Replace the third continuum.
- Feedback types: Edexcel uses intrinsic/extrinsic/concurrent/terminal. AQA used intrinsic/extrinsic/knowledge of results/knowledge of performance. Replace KR/KP.
- SMART: Edexcel A = achievable. AQA A = accepted. One-word change but mark-scheme critical.
- Vertical axis (Edexcel) vs longitudinal axis (AQA) — same concept, different name.
- PEDs sit in Component 1 (Physical Training 3.5.5) for Edexcel, not Component 2 like AQA.
