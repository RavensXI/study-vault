# AQA Religious Studies A 8062 Gap-Fill — Related Media Curation Prompt

You are curating `related_media` for a small batch of GCSE Religious Studies (AQA 8062) lessons covering the 12 new gap-fill units (5 religions × Beliefs + Practices, plus Themes C and F). Quality bar is high: students should be able to **click any link and immediately reach the content** (a YouTube watch page that plays, a Spotify / Apple Podcasts episode page that plays, a study tool that loads, an article that opens). The single exception is Movies / TV / Documentaries — those use JustWatch UK aggregator pages because most films / shows aren't free-to-watch directly.

## Files to read

1. `docs/RELATED_MEDIA_PIPELINE.md` — full pipeline rules (read fully)
2. The lesson JSONs at `scripts/_content_religious-education-gap-fill/lessons/{lesson_slug}.json` for the lessons you're assigned. You'll write back to each.
3. **Reference for podcast format**: existing AQA RE Christianity / Islam lessons in Supabase (subject `8efd391b-1981-46a2-a22f-0baf45925c2b`, units `christianity-beliefs`, `christianity-practices`, `islam-beliefs`, `islam-practices`). Podcasts on those lessons follow the StudyVault NotebookLM pattern — borrow that pattern as a placeholder for these gap-fill lessons (Tom adds the real episode URLs in the manual NotebookLM pass).

## Output schema — MANDATORY format

For each lesson in your batch, ADD a `related_media` field to its lesson JSON. **Schema is a list of category groups, each with a nested `items` array** (NOT a flat list of per-item entries):

```json
"related_media": [
  {
    "category": "Podcasts",
    "emoji": "🎙️",
    "items": [
      {
        "title": "Episode title",
        "description": "1-line context",
        "url": "https://open.spotify.com/episode/... OR https://podcasts.apple.com/.../id123?i=456 OR https://youtu.be/..."
      }
    ]
  },
  {
    "category": "Videos & Channels",
    "emoji": "📺",
    "items": [
      { "title": "...", "description": "...", "url": "https://www.youtube.com/watch?v=VIDEO_ID" }
    ]
  },
  {
    "category": "Documentaries",
    "emoji": "🎬",
    "items": [
      { "title": "Title (Year)", "description": "...", "url": "https://www.justwatch.com/uk/movie/SLUG" }
    ]
  },
  {
    "category": "Study Tools",
    "emoji": "🛠️",
    "items": [
      { "title": "...", "description": "...", "url": "https://..." }
    ]
  },
  {
    "category": "Articles & Reading",
    "emoji": "📰",
    "items": [
      { "title": "...", "description": "...", "url": "https://..." }
    ]
  }
]
```

**CRITICAL — DO NOT** flatten this into per-item entries with a `category` key on each item. The `_verify_subject_build.py` validator and `lesson-loader.js` BOTH expect grouped categories with nested `items`. Per the StudyVault `feedback_related_media_format.md` rule.

**IMPORTANT — exact category names** (the `_verify_subject_build.py` validator hard-checks for these strings, so don't paraphrase):
- `Podcasts`
- `Videos & Channels`
- One of: `Movies` / `TV Shows` / `Documentaries` (pick exactly one — `Documentaries` is usually best for RE because there's a strong canon of religion documentaries; `TV Shows` works for Theme F lessons that touch on contemporary social issues)
- `Study Tools`

`Articles & Reading` is optional but recommended for RE — there's plenty of free explanatory writing from BBC Religion, BBC Bitesize and the major religious organisations.

If you cannot find an episode-level Podcast for a niche topic, leave a single placeholder: `{ "title": "Lesson Podcast", "description": "Generated by NotebookLM — added later by Tom", "url": "https://example.com/placeholder" }` — Tom replaces it during the manual NotebookLM pass. The verifier still passes because the **Podcasts** category is present with at least one item.

## Hard rules

- **Each lesson: ≥6 items total**, spanning the four required categories (≥1 each: Podcasts, Videos & Channels, one of Movies / TV Shows / Documentaries, Study Tools). A 5th category (Articles & Reading) is welcome.
- **Every URL must be clickable** and take the student straight to the content — not a search results page, not a homepage.
- **YouTube URLs** must be `https://www.youtube.com/watch?v=VIDEO_ID` or `https://youtu.be/VIDEO_ID`. **Verify each** with the oembed endpoint before adding:
  ```
  curl -s "https://www.youtube.com/oembed?url=https%3A//www.youtube.com/watch%3Fv%3DVIDEO_ID&format=json"
  ```
  If oembed returns an error or HTTP non-200, drop it. **DO NOT use HEAD requests** — YouTube returns 200 even for deleted videos.
- **Podcasts**: link to a specific EPISODE on Spotify, Apple Podcasts, Google Podcasts, or YouTube. Not the show's homepage.
- **Movies / TV / Documentaries**: use JustWatch UK URLs (`https://www.justwatch.com/uk/movie/{slug}` or `https://www.justwatch.com/uk/tv-show/{slug}`).
- **No Wikipedia in primary slots** — fine as a Study Tool occasionally but ≤1 of 6.
- **No Save My Exams / PMT / MME / Revision World / Study Mind / Primrose Kitten** — banned per pipeline doctrine.
- **No reproduction of past papers, mark schemes, or exam-board "model answers"** — that's the copyright moat we're protecting.
- **Tonal match**: items must connect to the LESSON's topic, not just the subject. A BBC Religion podcast on the Mool Mantra goes on Sikhism Beliefs L1, not Sikhism Practices L4.
- **UK-relevance preferred**: students are British. Pick UK examples and outlets (BBC Bitesize, BBC Religion & Ethics, BBC Sounds, the Religion Media Centre) first; international fine if best fit.
- **Religious neutrality**: pick sources that present each tradition factually. Avoid evangelistic or polemical channels (e.g. dedicated atheist debate channels for the religion lessons; dedicated apologetics channels claiming one religion is uniquely true). For Theme C Existence of God, BBC Ethics on the cosmological argument is fine; "Why Atheism is the Only Logical Position"-style content is not.
- **Theme F sensitivity**: avoid sources that take strong polemical positions on contested issues. BBC, Religion Media Centre, Amnesty UK, Theos Think Tank are usually safe. Tabloid coverage of contested LGBTQ+ / women's rights / race issues is not.

## UK-first source biases per religion

### Buddhism
- **BBC Bitesize Buddhism** — `https://www.bbc.co.uk/bitesize/topics/zh89y4j` (AQA Buddhism index)
- **BBC Religion & Ethics — Buddhism**
- **The Buddhist Society UK** — explainer pages
- **BBC Sounds — *The Way of the Buddha*** (4-episode 2021 series with Bidisha)
- **BBC Sounds — *In Our Time* on Buddhism, the Buddha, the Four Noble Truths, Bodhisattvas**
- **YouTube channels:** Religion For Breakfast (Andrew Mark Henry, university-trained, neutral), Mr McMillan REOnline, Religious Studies Daily, FreeJupiterRE.

### Catholic Christianity
- **Catholic Education Service** — UK Catholic schools' resource hub
- **Vatican.va** — for sourcing official documents (cite carefully, paraphrase rather than quote at length)
- **CAFOD** — `cafod.org.uk` (the Catholic agency for overseas development is named in the spec)
- **BBC Religion's Catholic content** — articles and broadcasts
- **BBC Sounds — *Sunday* (Sunday on Radio 4)** — weekly religious affairs programme often covering Catholic stories
- **YouTube channels:** Bishop Robert Barron's Word on Fire (US-based, mainstream Catholic), Catholic News Agency.
- For Lourdes / Walsingham pilgrimage lessons: official pilgrimage site pages, BBC Religion features.

### Hinduism
- **BBC Bitesize Hinduism** — `https://www.bbc.co.uk/bitesize/topics/zsx239q` (AQA Hinduism index)
- **ISKCON UK** — with a caveat that ISKCON represents one Vaishnavite tradition (Gaudiya Vaishnavism), not all Hindu thought
- **Hindu Council UK**
- **BBC Religion's Hinduism articles**
- **BBC Sounds — *The Way of the Buddha* style content for Hinduism** (search BBC Sounds for "Hinduism")
- **YouTube channels:** Religion For Breakfast (good neutral coverage), Mr McMillan REOnline, FreeJupiterRE, Hare Krishna Mantra Meditation channel.
- For Diwali / Holi: BBC Newsround, BBC Religion festivals coverage.

### Judaism
- **BBC Bitesize Judaism** — `https://www.bbc.co.uk/bitesize/topics/znpcwmn` (AQA Judaism index)
- **Board of Deputies of British Jews** — `bod.org.uk`
- **World Jewish Relief**
- **BBC Religion's Judaism articles** — strong on UK Jewish life
- **The Jewish Museum London** — explainer resources
- **My Jewish Learning** — high-quality educational content (US-based but rigorous and used in UK schools)
- **BBC Sounds — *In Our Time* on Maimonides, the Talmud, Pikuach Nefesh, the Shoah**
- **YouTube channels:** Jewish Learning Institute, Religion For Breakfast, Mr McMillan REOnline.

### Sikhism
- **BBC Bitesize Sikhism** — `https://www.bbc.co.uk/bitesize/topics/zsjpyrd` (AQA Sikhism index)
- **The Sikh Network UK** — `thesikhnetwork.com`
- **Network of Sikh Organisations UK** — `nsouk.co.uk`
- **BBC Religion's Sikhism articles**
- **BBC Sounds — coverage of Vaisakhi, the Golden Temple, Sikh history**
- **YouTube channels:** SikhNet (US-based but mainstream Sikh educational), Religion For Breakfast, Basics of Sikhi (UK-based, does take a particular sahajdhari-friendly stance — flag in description if used).
- For Vaisakhi / Diwali / Gurpurbs: BBC Newsround features.

### Theme C: Existence of God & Revelation
- **BBC Bitesize Philosophy and Ethics**
- **BBC Religion's philosophy of religion section**
- **BBC Sounds — *In Our Time* on Aquinas, Paley, the Design Argument, the Cosmological Argument, the Problem of Evil, Hume on Miracles**
- **YouTube channels:** Crash Course Philosophy (US, but YouTube-pitched), Religion For Breakfast, PhilosophyTube (UK, philosophy graduate Abigail Thorn — pick non-polemical episodes), Mr McMillan REOnline.
- **Documentaries:** *The Question of God* (PBS, Freud vs C.S. Lewis), *Why Are We Here?* style content.
- **Articles:** Stanford Encyclopedia of Philosophy entries (free, scholarly), BBC Religion philosophy-of-religion coverage.

### Theme F: Religion, Human Rights & Social Justice
- **BBC Bitesize Philosophy and Ethics — Human Rights and Social Justice**
- **BBC Religion's social-justice coverage**
- **Amnesty International UK** — `amnesty.org.uk` (especially for racial discrimination, freedom of religion, and human rights coverage)
- **The Equality and Human Rights Commission** — `equalityhumanrights.com`
- **Theos Think Tank** — `theosthinktank.co.uk` (rigorous, UK-based research on religion and society)
- **BBC Sounds — *Sunday*, *Beyond Belief* (Ernie Rea's discussion programme on Radio 4)**
- **YouTube channels:** Crash Course Religions, Mr McMillan REOnline, Religion For Breakfast.
- **Articles:** BBC Religion features, *The Guardian* religion-section pieces (where free), *The Conversation UK* religion articles.
- **Caveat**: Theme F covers contested ground. Pick analytical sources, not advocacy sources. *Beyond Belief* is excellent because it puts contrasting religious views in dialogue.

## Verification step (mandatory)

For each YouTube URL, run the oembed check before including. Drop and replace if it fails. For other URLs, sanity-check by reading the URL — does it look like a direct content page? If `?search=` or homepage-like (e.g. `https://www.bbc.co.uk/bitesize`) — replace with a deeper link.
