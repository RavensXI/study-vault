# Unity College Content Accuracy Spot-Check — 5 April 2026

Subjects checked: Combined Science (AQA 8464), English Language (AQA 8700), Drama (OCR J316).

Method: For each subject, the exam specification markdown was read and compared against (a) lesson titles across all units for topic coverage mapping, and (b) the `content_html` of three sampled lessons (first, middle, last) for factual accuracy and spec alignment.

## 3. Drama (OCR J316)

**12 lessons across 2 units — Blood Brothers (8 lessons) and Rise Up (4 lessons).**

### Topic Coverage Mapping

OCR J316 has three components:
- **Component 01/02: Devising Drama** (30%) — NEA, internally assessed
- **Component 03: Presenting and Performing Texts** (30%) — NEA, visiting examiner
- **Component 04: Drama: Performance and Response** (40%) — Written exam, 1h30m

  - Section B (30 marks): Analysis and evaluation of a live theatre performance

The Unity course uses **Blood Brothers** as the Component 04 Section A set text and **Rise Up** as the Component 04 Section B live theatre performance for evaluation.
