Explicit & Implicit Information

Explicit = stated directly. You can underline the exact words.

Implicit = suggested through clues. You must infer the meaning.

  1. Read the specified lines carefully
  2. Ask: “Can I point to the exact words?”
  3. Yes → explicit
  4. No, but evidence suggests it → implicit
  5. No evidence at all → not supported
